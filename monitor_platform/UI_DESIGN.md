# 监测平台现代化UI设计说明

## 设计理念

### 1. 深色主题
- **主背景**: 深蓝黑渐变 (#0f172a → #1e1b4b)
- **卡片背景**: 半透明玻璃态 (backdrop-filter: blur)
- **文字颜色**: 层级分明的灰白色系

### 2. 玻璃态设计
```css
background: rgba(30, 41, 59, 0.7);
backdrop-filter: blur(20px);
border: 1px solid rgba(255, 255, 255, 0.1);
```

### 3. 渐变装饰
- 顶部蓝色光晕 (20% 20%)
- 右下角紫色光晕 (80% 80%)
- 中心青色微光 (50% 50%)

## 组件设计

### 统计卡片
- **尺寸**: 100% 宽度，均分4列
- **高度**: 自适应内容
- **顶部线条**: 3px 渐变色标识类型
- **图标**: 40×40px，带背景色
- **数值**: 32px 粗体
- **标签**: 12px 次要文字

### 运动控制盘
```
        [↰ 左转]    [↑ 前进]    [↱ 右转]
        [← 左移]    [⏹ 停止]    [→ 右移]
                    [↓ 后退]
```
- **按钮尺寸**: 60×50px
- **图标**: 18px
- **标签**: 11px
- **悬停**: 上移2px + 背景渐变

### 状态指标
- **布局**: 2×3 网格
- **数值**: 18px 粗体
- **进度条**: 4px 高，平滑过渡
- **颜色状态**: 正常→警告→危险

## 动效设计

### 页面加载
- 背景渐变动画 (3s ease-out)
- 卡片淡入上移 (0.5s staggered)

### 交互反馈
- **悬停**: translateY(-4px) + 阴影增强
- **点击**: translateY(0) + 背景色变化
- **连接**: 脉冲动画 (2s infinite)
- **告警**: 滑入动画 (0.3s ease)

### 数据更新
- **数值**: 渐变色过渡 (0.5s)
- **进度条**: 宽度平滑变化
- **表格行**: 悬停高亮
