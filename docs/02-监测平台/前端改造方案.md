## 接口替换方案

### 当前接口（Spring Boot）
```typescript
GET  /api/system/user/list
POST /api/system/user/add
PUT  /api/system/user/edit
DELETE /api/system/user/delete
```

### 目标接口（FastAPI + WebSocket）
```typescript
// HTTP API
GET  /api/status          // 系统状态
GET  /api/robot           // 机器狗状态
POST /api/control/{action} // 运动控制
POST /api/key/{key}       // 键盘按键
POST /api/demo            // 启动演示

// WebSocket实时数据
WS   ws://192.168.1.200:8765/ws
消息: inspection_result, temperature_alert, heartbeat, system_status
```

## 技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| WebSocket断连 | 数据中断 | 自动重连机制 + 心跳检测 |
| 实时数据量大 | 性能问题 | 虚拟滚动 + 数据节流 |
| 视频流延迟 | 体验差 | WebRTC优化 |
