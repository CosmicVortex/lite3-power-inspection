## 核心功能

### 1. 实时监控大屏
- 电池电量环形图（带颜色指示）
- 温度实时显示（带阈值标记）
- 告警时间线
- D-Pad游戏手柄风格控制器
- 快捷操作按钮

### 2. 温度监测
- ECharts实时曲线
- 双级告警阈值线（45℃/50℃）
- 温度状态指示（正常/预警/告警）
- 告警计数

### 3. 裂缝检测
- 检测结果表格
- 缺陷类型标签
- 置信度显示
- 位置信息

### 4. 设备控制
- D-Pad方向控制
- 起立/趴下切换
- 左转/右转
- 紧急停止
- 运动模式选择
- 速度调节

### 5. 视频流
- 可见光视频播放
- 热成像视频播放
- 截图功能
- 录制功能

### 6. 历史记录
- 时间范围筛选
- 巡检记录
- 告警记录
- 状态记录

## 技术特点

| 特性 | 说明 |
|------|------|
| 响应式布局 | 支持不同屏幕尺寸 |
| 暗黑模式 | Element Plus主题切换 |
| 实时数据 | WebSocket自动重连 |
| 状态管理 | Pinia响应式存储 |
| 图表可视化 | ECharts实时曲线 |
| 路由守卫 | 页面标题自动设置 |

## 后端对接

### WebSocket接口
```
ws://192.168.1.200:8765/ws
消息格式: { msgId, ts, deviceId, type, payload }
```

### HTTP API
```
GET  /api/status      - 系统状态
GET  /api/robot       - 机器狗状态
POST /api/control/{action} - 运动控制
POST /api/key/{key}   - 键盘按键
POST /api/demo        - 启动演示
```

## 部署说明

### 开发环境
```bash
cd frontend
pnpm install
pnpm dev  # http://localhost:5173
```

### 生产构建
```bash
pnpm build
# 输出到 ../monitor_platform/frontend_dist/
```

### 与FastAPI集成
将 dist 目录复制到 monitor_platform/frontend_dist/，修改 server.py 挂载静态文件。
