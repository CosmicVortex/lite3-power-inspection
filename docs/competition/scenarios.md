# 演示场景设计

## 场景概述

本系统演示两个核心场景，在抽水蓄能电站沙盘模型上进行。

---

## 场景一：混凝土裂缝视觉检测

### 演示目标
展示机器狗搭载双光谱云台相机，对混凝土结构进行自动巡检，识别裂缝及表面缺陷。

### 技术原理

#### 两阶段检测流程

```
阶段一：广角巡检发现
┌─────────────────────────────────────────────┐
│ 可见光主码流 RTSP (广角端, 1×变焦)          │
│     ↓                                        │
│   抽帧 5 Hz                                  │
│     ↓                                        │
│ [YOLOv8-s] 缺陷检测（裂缝二分类）            │
│     │  TensorRT INT8, ≈15ms/帧               │
│     ↓ 置信度 > 0.5                           │
│   触发变焦指令 → ptz.zoom_ctrl(zoom=10)      │
│                云台自动对焦 (AF)             │
│                等待 500ms 稳定               │
└─────────────────────────────────────────────┘

阶段二：精细检测测量
┌─────────────────────────────────────────────┐
│ 可见光主码流 RTSP (10×变焦, 稳定后)         │
│     ↓                                        │
│   抽帧 15 Hz, 取 5 帧                        │
│     ↓                                        │
│ [U-Net] 裂缝分割 → 骨架提取                  │
│     ↓                                        │
│ [宽度测量]                                   │
│   沿骨架法线方向计算像素跨度                 │
│   灰度矩亚像素法 (精度 0.05px)               │
│   换算为 mm (基于变焦倍数标定)               │
│     ↓                                        │
│   5 帧中值滤波 → 输出宽度/长度               │
│     ↓                                        │
│   结构化告警事件 + 图像快照                  │
└─────────────────────────────────────────────┘
```

#### 0.1mm 精度保障措施

| 措施 | 说明 |
|------|------|
| 变焦倍数标定 | 开赛前用 0.1mm 标定板在 10× 变焦下标定像素精度 |
| 亚像素细分 | 灰度矩法，精度提升至 0.05 像素 |
| 多帧融合 | 定点停留采集 5 帧，取中位数抑制抖动 |
| 置信度过滤 | 宽度 < 0.05mm 或置信度 < 0.6 的检测结果丢弃 |
| 三轴增稳 | 云台自带三轴增稳，行进中画面稳定 |
| 自动对焦 | 变焦后调用云台 AF 功能，10~20s 内图像清晰 |

#### 精度校核

| 阶段 | 工作距离 | 变焦倍数 | 水平视场角 | 水平视野 | 像素精度 | 用途 |
|------|----------|----------|-----------|----------|----------|------|
| 巡检发现 | 300mm | 1× (广角 3.2mm) | 90.3° | ≈603mm | ≈0.157mm/px | 大范围扫描，发现疑似缺陷 |
| 精细检测 | 200mm | 10× (望远 32mm) | 20.4° | ≈72mm | ≈0.019mm/px | 精确测量裂缝宽度 |

**精度结论**：精细检测阶段像素精度 0.019mm/px，0.1mm 裂缝约占 5.3 像素宽，配合亚像素细分（0.05px）可稳定检出。

## 场景二：大体积混凝土温度监测

### 演示目标
展示机器狗搭载红外热像仪，实时监测混凝土结构温度，实现双级告警。

### 双级告警逻辑

```
温度监测流程：
┌─────────────────────────────────────────────┐
│ 热成像 RTSP 流 (640×512)                   │
│     ↓                                        │
│   边缘层解析温度数据                         │
│     ↓                                        │
│   判断温度值：                               │
│   ├─ T < 45℃ → 正常状态                    │
│   ├─ 45℃ ≤ T < 50℃ → WARN (黄色)           │
│   └─ T ≥ 50℃ → CRITICAL (红色)             │
└─────────────────────────────────────────────┘

去抖机制：
• WARN（45℃）：连续 5 帧（100ms）满足阈值才触发
• CRITICAL（50℃）：连续 3 帧（60ms）满足阈值立即触发
• 状态转换：CRITICAL 触发后，温度回落至 45~50℃ 仍保持 30s
```

### 沙盘温升模块适配

| 时段 | 温度 | 状态 | 灯带颜色 |
|------|------|------|----------|
| 0~90s | 40℃→46℃ | 升温过程 | 绿色 |
| 90~120s | 46℃→51℃ | WARN→CRITICAL | 黄→红 |
| 降温后 | <45℃ | 恢复正常 | 绿色 |

## 应急预案

| 异常情况 | 应对措施 |
|----------|----------|
| 机器狗偏离航点 | 自主导航自动修正；偏差>10cm时手动遥控归位 |
| 视频流卡顿 | 切换辅码流；云台自动降帧至10fps |
| WiFi断连 | SQLite本地缓存，恢复后批量补传 |
| 检测漏报 | 关键点位预设"强制抓拍"指令 |
| 温度未达阈值 | 预热至40℃起始；必要时调低CRITICAL阈值至48℃ |
| 云台角度偏差 | 开赛前浏览器WEB界面标定角度 |
| 自动对焦慢 | 变焦后预留2s稳定；必要时半自动一次聚焦 |
| 电量不足 | 开赛前确保≥90%；演示全程≤12分钟 |
