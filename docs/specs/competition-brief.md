# 竞赛任务书

## 项目名称
广西电力职院机器狗电力巡检国赛

## 项目背景
随着智能电网建设的推进，电力巡检自动化成为重要发展方向。四足机器人凭借其地形适应性，在复杂电力环境巡检中具有独特优势。本项目基于云深处科技绝影Lite3专业版机器狗和数尔安防双光谱云台相机，开发抽水蓄能电站场景下的机器狗移动巡检方案，服务于职业高校技能竞赛演示。

## 演示要求

### 演示时长
- **总时长**: 约 12 分钟
- **包含**: 系统介绍 + 现场演示 + 数据汇报 + 答辩

### 演示场景
比赛现场搭建**抽水蓄能电站沙盘模型**，演示以下核心场景：

#### 场景一：混凝土裂缝视觉检测
- 机器狗搭载双光谱云台相机（800万像素 + 10倍光学变焦 + 三轴增稳）
- 对混凝土结构（调压井、压力隧洞、地下厂房顶部等）进行巡检
- 自动识别 **0.1mm 及以上裂缝**（亚像素测量精度）
- 自动识别**表面蜂窝麻面**缺陷
- 定位缺陷位置并告警
- 将检测数据实时上传至运维平台

#### 场景二：大体积混凝土温度监测
- 机器狗搭载红外热成像组件（640×512，测温-20~150℃）
- 对大体积混凝土结构进行温度扫描
- 实时监测温度分布
- **双级温度告警**：
  - 温度超过 **45℃** → 发出预警（WARN，黄色）
  - 温度高于 **50℃** → 发出告警（CRITICAL，红色）
- 将温度数据及热成像画面实时上传至运维平台

## 本项目范围

### ✅ 包含内容
1. **上装系统集成**
   - 双光谱云台相机安装与固定
   - 安装转接支架设计与加工（M6接口）
   - 上装外护罩设计与加工
   - 线缆管理与散热设计
   - 电源适配（Lite3 12V直接供电）

2. **数据采集与处理**
   - YOLOv8-s + U-Net 裂缝检测算法
   - 亚像素宽度测量（精度0.05px）
   - 温度双级告警逻辑（45℃/50℃）
   - 蜂窝麻面分级算法
   - 灯带图像识别

3. **通信协议对接**
   - 数尔 WEB2.0 HTTP协议（MerlinSession）
   - WebSocket实时数据上报
   - HTTP REST接口
   - RTSP视频流订阅
   - SQLite本地缓存（断网续传）

4. **与第三方平台对接**
   - 状态/轨迹/告警实时推送
   - Mock Server联调测试
   - 接口文档交付

### ❌ 不包含内容
- 监测平台开发（第三方负责）
- 沙盘模型制作（现场搭建）
- 机器狗本体硬件改造
