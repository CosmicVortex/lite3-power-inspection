## 二、Critical Bug修复

### 2.1 WebSocketGateway.flush_queue() 事件循环Bug

**文件**: `src/gateway/websocket_client.py:181`

**原代码**:
```python
asyncio.get_event_loop().run_until_complete(_flush())
```

**问题**: 
- 在非异步上下文中调用会创建新事件循环
- 在当前运行的asyncio事件中调用会导致`RuntimeError: This event loop is already running`

**修复**:
```python
def flush_queue(self):
    if not self._queue:
        return
    logger.info(f"刷新缓存队列，共{len(self._queue)}条消息")
    self._flush_sync()

def _flush_sync(self):
    """同步刷新缓存队列（线程安全）"""
    import asyncio as _asyncio
    loop = _asyncio.new_event_loop()
    try:
        _asyncio.set_event_loop(loop)
        async def _flush():
            for message in self._queue[:]:
                try:
                    await self._ws.send(json.dumps(message, ensure_ascii=False))
                    self._queue.remove(message)
                except Exception as e:
                    logger.error(f"缓存消息重发失败: {e}")
                    break
        loop.run_until_complete(_flush())
    finally:
        loop.close()
```

**影响**: 重连时的缓存消息重发功能

### 2.2 SnapshotServer.start() 未定义变量

**文件**: `src/services/snapshot_server.py:44`

**原代码**:
```python
self._server = await loop.create_server(...)
```

**问题**: 
- `loop`变量未定义
- 应使用`asyncio.get_running_loop()`或在async函数中直接使用`asyncio.get_running_loop()`

**修复**:
```python
self._server = await asyncio.get_running_loop().create_server(...)
```

**影响**: 快照HTTP服务启动

### 2.3 SnapshotServer全局变量语法错误

**文件**: `src/services/snapshot_server.py:121-124`

**原代码**:
```python
_loop = asyncio.get_event_loop() if asyncio.get_event_loop().is_running() else None
```

**问题**:
- 在Python 3.10+中，如果当前没有运行中的事件循环，会抛出`RuntimeError`
- 条件表达式缩进错误导致语法错误

**修复**:
```python
_loop = None
```

**影响**: 模块加载时的全局变量初始化
