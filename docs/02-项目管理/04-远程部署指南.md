## 一、网络拓扑设计

### 1.1 离线网络架构

由于绝影Lite3机器狗主机未接入互联网，采用**本地WiFi热点模式**进行远程访问：

```
│                      现场演示环境                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌──────────────┐    WiFi    ┌──────────────┐             │
│   │  笔记本电脑   │ ◄────────► │  感知主机     │             │
│   │  (192.168.1.1)│            │  (Jetson NX) │             │
│   └──────┬───────┘            │  (待确认IP)  │             │
│          │                     └──────┬───────┘             │
│          │ WiFi热点                   │ UDP/WebSocket       │
│          │                            │                    │
│          ▼                     ┌──────▼───────┐            │
│   ┌──────────────┐            │  运动主机     │            │
│   │  监测平台     │◄──────────►│  (RK3588)     │            │
│   │ (Web UI)     │  HTTP      │  (192.168.1.103)│           │
│   └──────────────┘            └──────┬───────┘            │
│                                     │                     │
│                              ┌──────▼───────┐             │
│                              │  数尔云台     │             │
│                              │  (192.168.1.108)│           │
│                              └──────────────┘             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| 设备 | IP地址 | 用途 |
|------|--------|------|

## 二、远程访问方案

### 2.1 方案A：SSH远程登录（推荐）

#### SSH账户信息

| 参数 | 值 | 来源 |
|------|-----|------|
| 用户名 | `ysc` | 《感知开发手册V2.2.3》第8页 |
| 密码 | `'`（英文单引号） | 《感知开发手册V2.2.3》第8页 |
| 连接IP | `192.168.1.103` | 《感知开发手册V2.2.3》第7页 |

#### 步骤1：笔记本电脑配置WiFi热点

```bash
# Ubuntu系统创建WiFi热点
sudo nmcli device wifi hotspot ifname wlan0 ssid "Lite3-Deploy" password "deploy123"

# 查看本机IP地址
ip addr show
# 记录 wlan0 的IP地址，例如: 192.168.1.1
```

#### 步骤2：配置感知主机网络

```bash
# 在Jetson NX上配置静态IP
sudo nano /etc/netplan/01-netcfg.yaml

# 添加以下内容
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 192.168.1.103/24
      nameservers:
        addresses:
          - 8.8.8.8
      routes:
        - to: default
          via: 192.168.1.1

# 应用配置
sudo netplan apply
```

#### 步骤3：SSH登录

```bash
# 从笔记本电脑SSH登录到感知主机
ssh ysc@192.168.1.103

# 密码输入英文单引号: '
# 注意：若提示密码错误，尝试先按一次Shift键切换英文输入法

# 首次登录建议配置SSH密钥认证（推荐）
ssh-copy-id ysc@192.168.1.103
```

### 2.2 方案B：NoMachine远程桌面

#### 步骤1：下载安装NoMachine

在开发主机（笔记本电脑）上下载并安装NoMachine软件：
- 下载地址：https://www.nomachine.com/download

#### 步骤2：创建新连接

1. 打开NoMachine软件，点击"New"/"Add"新建连接
2. 配置参数：
   - **Protocol**: NX
   - **Host**: 192.168.1.103
   - **Authentication**: Use password authentication
   - **Proxy**: 不勾选
3. 保存连接

#### 步骤3：远程登录

1. 点击创建的连接图标
2. 输入用户名：`ysc`
3. 输入密码：`'`（英文单引号）
4. 点击确定完成连接

> **注意**：连接后进行操作时，如果遇到锁屏界面，或者终端命令要求输入密码时，密码为 `'`（英文单引号）。

#### 故障排查

1. **密码错误问题**
   - 若输入密码 `'` 时显示密码错误，请尝试敲击一次Shift按键切换英文输入法后，再输入 `'`

2. **远程桌面白屏问题**
   - 点击NoMachine右上角的"Settings"
   - 选择左下角"Server Preferences"
   - 选择右上方"Updates"
   - 点击"Check now"进行更新
   - 更新完成后再次尝试远程连接

3. **session negotiation failed错误**
   ```bash
   ssh ysc@192.168.1.103           # 密码是单引号
   sudo su 
   cd /usr/NX/var/db/limits/ 
   ls                        # 列出limits目录下的文件
   rm xxxxx xxxxxx xxxxxx       # 删除各个文件
   ```
   若以上操作之后还是显示"session negotiation failed"，则再次进行以上操作，并使用 `sudo reboot` 重启感知主机。

### 2.3 方案C：USB网络共享

如果WiFi热点不稳定，可使用USB以太网共享：

```bash
# Jetson NX端启用USB网络共享
sudo modprobe g_ether
sudo ifconfig usb0 192.168.1.103 netmask 255.255.255.0

# 笔记本电脑端配置
sudo ifconfig enp0s20 192.168.1.1 netmask 255.255.255.0
```

### 2.4 方案D：HDMI直连

绝影Lite3专业版/激光版支持通过背部HDMI口连接到感知主机桌面。

#### 设置图形化界面自启动

1. 使用HDMI线连接感知主机与显示器并将机器狗开机
2. 当系统出现 `[ OK ] Started Session 1 of user ysc.` 后即为开机成功
3. 使用USB接口连接键盘，按 `Ctrl+Alt+F3` 进入tty3终端
4. 输入用户名 `ysc` 和密码 `'`（英文单引号）登录
5. 执行以下命令：
   ```bash
   cd /usr/share/X11/xorg.conf.d/
   sudo mv xorg.conf ..
   # 输入密码: '
   ```
6. 重启机器狗，感知主机会自动进入图形化界面

#### 恢复tty3自启动

将xorg.conf恢复至原路径并重启机器狗：
```bash
cd /usr/share/X11/
sudo mv xorg.conf xorg.conf.d/
# 输入密码: '
```

## 三、应用程序部署流程

### 3.1 部署脚本

创建自动化部署脚本 `scripts/deploy.sh`：

```bash
#!/bin/bash
# 绝影Lite3电力巡检系统部署脚本

set -e

# SSH账户配置（来自感知开发手册V2.2.3）
SSH_USER="ysc"
REMOTE_HOST="${SSH_USER}@192.168.1.103"
PROJECT_DIR="/home/ysc/lite3-power-inspection"
PYTHON_VENV="$PROJECT_DIR/venv"

echo "=========================================="
echo "绝影Lite3电力巡检系统部署"
echo "=========================================="

# 1. 检查网络连接
echo "[1/6] 检查网络连接..."
ping -c 2 $REMOTE_HOST > /dev/null 2>&1 || {
    echo "❌ 无法连接到 $REMOTE_HOST"
    exit 1
}
echo "✅ 网络连接正常"

# 2. 创建项目目录
echo "[2/6] 创建项目目录..."
ssh $REMOTE_HOST "mkdir -p $PROJECT_DIR"

# 3. 同步代码文件
echo "[3/6] 同步代码文件..."
rsync -avz --progress \
    --exclude='__pycache__' \
    --exclude='*.pyc' \
    --exclude='.git' \
    --exclude='venv' \
    --exclude='data/' \
    ./ $REMOTE_HOST:$PROJECT_DIR/
echo "✅ 代码同步完成"

# 4. 安装Python依赖
echo "[4/6] 安装Python依赖..."
ssh $REMOTE_HOST "cd $PROJECT_DIR && python3 -m venv $PYTHON_VENV && \
    source $PYTHON_VENV/bin/activate && \
    pip install -r requirements.txt --quiet"
echo "✅ 依赖安装完成"

# 5. 创建数据目录
echo "[5/6] 创建数据目录..."
ssh $REMOTE_HOST "mkdir -p $PROJECT_DIR/{data,logs,models}"
echo "✅ 数据目录创建完成"

# 6. 验证部署
echo "[6/6] 验证部署..."
ssh $REMOTE_HOST "cd $PROJECT_DIR && source $PYTHON_VENV/bin/activate && \
    python3 -c 'from src.perception.temperature_monitor import TemperatureMonitor; m = TemperatureMonitor(); print(\"✅ 温度监测模块加载成功\")'"
ssh $REMOTE_HOST "cd $PROJECT_DIR && source $PYTHON_VENV/bin/activate && \
    python3 -c 'from src.gateway.udp_controller import UDPMotionController; print(\"✅ UDP控制器加载成功\")'"
ssh $REMOTE_HOST "cd $PROJECT_DIR && source $PYTHON_VENV/bin/activate && \
    python3 -c 'from src.gateway.ptz_controller import PtzController; print(\"✅ 云台控制器加载成功\")'"
ssh $REMOTE_HOST "cd $PROJECT_DIR && source $PYTHON_VENV/bin/activate && \
    python3 -c 'from src.storage.sqlite_cache import SQLiteCache; c = SQLiteCache(); print(\"✅ SQLite缓存加载成功\")'"

echo ""
echo "=========================================="
echo "✅ 部署完成！"
echo "=========================================="
echo ""
echo "SSH登录: ssh $REMOTE_HOST"
echo "项目目录: $PROJECT_DIR"
echo "Python环境: $PYTHON_VENV/bin/python3"
echo ""
echo "启动监测平台:"
echo "  cd $PROJECT_DIR && source $PYTHON_VENV/bin/activate && python3 src/app/monitor_platform.py"
echo ""
echo "访问地址: http://192.168.1.1:5000"
```

### 3.2 执行部署

```bash
# 赋予执行权限
chmod +x scripts/deploy.sh

# 执行部署
./scripts/deploy.sh
```

## 七、故障排查

### 7.1 网络连接问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| SSH连接超时 | 防火墙拦截 | `sudo ufw allow 22/tcp` |
| IP地址冲突 | DHCP分配重复 | 使用静态IP配置 |
| DNS解析失败 | 无外网DNS | 配置本地hosts或使用IP地址 |

### 7.2 服务启动失败

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| Flask端口被占用 | 5000端口被占用 | 修改端口或杀死占用进程 |
| SQLite权限不足 | 数据目录权限问题 | `chmod 755 data/` |
| Python模块导入失败 | 依赖未安装 | 重新执行 `pip install -r requirements.txt` |

### 7.3 硬件连接问题

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| UDP心跳无响应 | 运动主机未启动 | 检查运动主机电源和网络 |
| 云台登录失败 | 密码错误 | 确认默认账号admin/123456 |
| RTSP流无法拉取 | 端口被占用 | 检查554端口和相机配置 |
