## 五、已知限制与注意事项

### 5.1 模拟模式限制

当前系统默认运行在**模拟模式**，以下功能使用模拟数据：

1. **YOLO裂缝检测**: 随机生成符合规范的检测结果
2. **TensorRT推理**: 返回预设的模拟张量
3. **UNet分割**: 返回全零掩码（骨架实现）
4. **快照图片**: 使用PIL生成占位图片

### 5.2 真实模式要求

切换到真实模式需满足：

```bash
# 1. 准备模型文件
models/yolov8s-crack.trt    # YOLO裂缝检测模型
models/unet-crack.onnx      # U-Net裂缝分割模型

# 2. 安装推理依赖
pip install tensorrt onnx onnxruntime-gpu torch torchvision

# 3. 启动真实模式
python3 scripts/run_demo.py --mode real
```

## 六、部署建议

### 6.1 演示服务器部署

```bash
# 1. 克隆仓库
git clone https://github.com/CosmicVortex/lite3-power-inspection.git
cd lite3-power-inspection

# 2. 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动监测平台
python3 scripts/start_monitor.py
# 访问 http://localhost:8000

# 5. 启动演示（另一终端）
python3 scripts/run_demo.py --mode simulation
```

### 6.2 机器人端部署

```bash
# 使用一键部署脚本
bash scripts/deploy.sh

# 或手动部署
ssh admin@192.168.1.103 "mkdir -p /home/admin/lite3-power-inspection"
rsync -avz --exclude='.git' --exclude='venv' --exclude='data/' ./ admin@192.168.1.103:/home/admin/lite3-power-inspection/
ssh admin@192.168.1.103 "cd /home/admin/lite3-power-inspection && python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt"
```
