## 二、发现的问题

### 🔴 严重问题

#### 问题1: WebSocket服务器地址配置错误

**位置**: `config/inspection_config.yaml`, `src/app/inspector.py`

**问题描述**:
```yaml
communication:
  websocket:
    server_url: "ws://192.168.1.103:8765/ws"  # ❌ 错误
```

**影响**:
- 感知主机默认配置为连接自身IP（192.168.1.103:8765）
- 实际监测平台运行在独立笔记本上，IP地址不固定
- 部署时无法自动发现监测平台地址

**建议修复方案**:
```bash
# 方案1: 运行时环境变量覆盖
export WEBSOCKET_SERVER=ws://<笔记本IP>:8765/ws
python3 scripts/run_demo.py

# 方案2: 命令行参数
python3 scripts/run_demo.py --ws-url ws://<笔记本IP>:8765/ws

# 方案3: 配置文件自动检测
# 在config/inspection_config.yaml中添加注释说明
```

### 🟡 警告问题

#### 问题2: 监测平台WebSocket监听地址文档不一致

**位置**: `scripts/start_monitor.sh`

**当前实现**:
```bash
echo "  WebSocket:       ws://localhost:8765"
```

**实际监听**:
```python
# monitor_platform/server.py
config = uvicorn.Config(app, host="0.0.0.0", port=HTTP_PORT, log_level="info")
# HTTP: 8000, 但WebSocket服务器未正确启动
```

**问题**: 监测平台只启动了HTTP服务器（端口8000），WebSocket服务器（端口8765）未独立运行。

**影响**:
- 感知主机无法通过WebSocket上报数据
- 监测平台无法接收实时巡检数据
