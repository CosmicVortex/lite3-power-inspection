## 一、演示模式说明

### 1.1 模式定义

| 模式 | AI识别 | 本体数据 | 视频流 | 适用场景 |
|------|--------|----------|--------|----------|
| `simulation` | 模拟数据 | 物理模型 | 转发 | 无模型环境演示 |
| `real` | 真实推理 | 物理模型 | 转发 | 有模型环境演示 |
| `hybrid` | 混合模式 | 物理模型 | 转发 | 部分真实演示 |

### 1.2 核心特性

**✅ 本体数据真实性保障**

无论选择何种AI模式，以下数据始终基于物理模型生成：

- **电池状态**：根据负载动态放电（移动时耗电加速）
- **位置坐标**：基于运动学模型计算
- **关节角度**：逆运动学简化模型
- **温度数据**：随GPU负载变化
- **云台状态**：实时同步指令

**✅ 视频流转发**

- 可见光相机：RTSP → WebSocket → 监测平台
- 热成像相机：RTSP → WebSocket → 监测平台
- 帧率：15fps（可配置）
- 编码：JPEG压缩

## 二、使用方式

### 2.1 命令行参数

```bash
# 模拟模式（AI模拟，本体真实）
python3 src/app/main.py --mode simulation

# 真实模式（AI真实，本体真实）
python3 src/app/main.py --mode real

# 混合模式
python3 src/app/main.py --mode hybrid

# 指定WebSocket地址
python3 src/app/main.py --mode simulation --ws-url ws://192.168.1.200:8765/ws

# 禁用视频流
python3 src/app/main.py --mode simulation --no-video
```

### 2.2 完整部署命令

```bash
# 1. SSH登录感知主机
ssh ysc@192.168.1.103

# 2. 进入项目目录
cd ~/lite3-power-inspection

# 3. 离线安装依赖
./scripts/offline_install.sh sensors

# 4. 配置WebSocket地址
sed -i 's|ws://MONITOR_HOST:8765/ws|ws://<笔记本IP>:8765/ws|' config/inspection_config.yaml

# 5. 启动演示（混合模式+视频流）
python3 src/app/main.py --mode simulation --ws-url ws://<笔记本IP>:8765/ws
```

## 六、注意事项

1. **性能考虑**：视频流转发会占用带宽和CPU，可根据需要禁用
2. **帧率控制**：默认15fps，可通过修改代码调整
3. **网络要求**：WebSocket连接需保持畅通，断网自动重连
4. **RTSP地址**：需确保相机可访问，IP地址正确
