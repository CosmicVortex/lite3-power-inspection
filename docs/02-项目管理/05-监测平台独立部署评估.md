## 三、独立部署方案

### 方案A：Python脚本直跑（最简单）

```bash
# 1. 安装依赖（约30秒）
pip install -r monitor_platform/requirements.txt

# 2. 启动服务
python3 monitor_platform/server.py
```

**优点**: 
- 零配置，开箱即用
- 适合快速测试

**缺点**:
- 需要Python环境
- 不适合非技术人员

---

### 方案B：便携式部署包（推荐）

#### 创建便携包

```python
# scripts/package_monitor.py
import zipfile
import subprocess
from pathlib import Path

def create_portable_package():
    """创建便携部署包"""
    package_name = "monitor-platform-portable.zip"
    
    # 收集文件
    files_to_include = [
        "monitor_platform/server.py",
        "monitor_platform/requirements.txt",
        "scripts/start_monitor.py",
    ]
    
    with zipfile.ZipFile(package_name, 'w', zipfile.ZIP_DEFLATED) as zipf:
        for file_path in files_to_include:
            if Path(file_path).exists():
                zipf.write(file_path)
    
    # 创建启动脚本
    startup_script = '''#!/bin/bash
# 监测平台启动脚本（便携版）
set -e

echo "🚀 启动监测平台..."
echo ""

# 检查Python
if ! command -v python3 &> /dev/null; then
    echo "❌ 错误: 未找到Python3"
    exit 1
fi

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
echo "📦 安装依赖..."
pip install -q -r monitor_platform/requirements.txt

# 启动服务
echo "✅ 启动监测平台..."
echo "   访问地址: http://localhost:8000"
echo "   WebSocket: ws://localhost:8765"
echo ""
python3 monitor_platform/server.py
'''
    
    with open("start_monitor.sh", "w") as f:
        f.write(startup_script)
    
    import os
    os.chmod("start_monitor.sh", 0o755)
    
    # 打包启动脚本
    with zipfile.ZipFile(package_name, 'a') as zipf:
        zipf.write("start_monitor.sh")
    
    print(f"✅ 便携包已创建: {package_name}")
    print(f"   大小: {Path(package_name).stat().st_size / 1024:.1f} KB")

if __name__ == "__main__":
    create_portable_package()
```

#### 使用步骤

```bash
# 1. 创建便携包
python3 scripts/package_monitor.py

# 2. 传输到目标电脑
scp monitor-platform-portable.zip user@target:/tmp/

# 3. 目标电脑上解压并运行
unzip monitor-platform-portable.zip -d ~/monitor-platform
cd ~/monitor-platform
./start_monitor.sh
```

**优点**:
- 自包含，无需预装Python
- 自动安装依赖
- 跨平台兼容

**缺点**:
- 首次启动需下载依赖（约30秒）

### 方案C：PyInstaller打包（最便捷）

```bash
# 1. 安装打包工具
pip install pyinstaller

# 2. 打包监测平台
pyinstaller --onefile \
    --name monitor-platform \
    --add-data "monitor_platform:monitor_platform" \
    monitor_platform/server.py

# 3. 生成可执行文件
# dist/monitor-platform (Linux)
# dist/monitor-platform.exe (Windows)
```

**优点**:
- 单文件，零依赖
- 双击即可运行
- 适合分发给非技术人员

**缺点**:
- 打包时间较长（约2分钟）
- 文件大小较大（约30MB）
- 需要对应平台的编译器

### 方案D：Docker容器化（最专业）

#### Dockerfile

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 复制依赖文件
COPY monitor_platform/requirements.txt .

# 安装依赖
RUN pip install --no-cache-dir -r requirements.txt

# 复制应用代码
COPY monitor_platform/ ./monitor_platform/
COPY scripts/start_monitor.py .

# 暴露端口
EXPOSE 8000 8765

# 启动服务
CMD ["python3", "monitor_platform/server.py"]
```

#### 构建和运行

```bash
# 构建镜像
docker build -t monitor-platform:v1.7 .

# 运行容器
docker run -d \
  --name monitor-platform \
  -p 8000:8000 \
  -p 8765:8765 \
  monitor-platform:v1.7

# 访问
echo "http://localhost:8000"
```

**优点**:
- 环境隔离
- 部署简单
- 可扩展性强

**缺点**:
- 需要Docker环境
- 镜像大小约200MB

## 四、网络配置建议

### 4.1 默认配置

```python
# monitor_platform/server.py
WS_HOST = "0.0.0.0"      # 监听所有接口
WS_PORT = 8765
HTTP_PORT = 8000
```

### 4.2 笔记本部署注意事项

| 问题 | 解决方案 |
|------|----------|
| 防火墙拦截 | 允许8000和8765端口入站 |
| IP地址变化 | 使用`0.0.0.0`监听所有接口 |
| 网络隔离 | 确保与机器狗在同一WiFi |
| 端口冲突 | 检查是否有其他服务占用8000/8765 |

### 4.3 验证连通性

```bash
# 本地测试
curl http://localhost:8000/docs

# 从机器狗测试
# 在机器狗上执行:
curl http://192.168.1.x:8000/docs  # x为笔记本IP最后一段
```

## 八、故障排查

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法访问8000端口 | 防火墙阻止 | 关闭防火墙或添加规则 |
| WebSocket连接失败 | IP地址错误 | 使用`ipconfig`查看真实IP |
| 端口被占用 | 其他服务占用 | `lsof -i :8000`查找进程 |
| 依赖安装失败 | 网络问题 | 使用国内镜像源 |
