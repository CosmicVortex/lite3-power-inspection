## 三、离线安装包准备建议

### 3.1 推荐方案：预生成离线包

在赛前准备阶段（有网络环境），执行以下命令生成离线包：

```bash
cd ~/lite3-power-inspection

# 生成Python依赖离线包
python3 scripts/package_offline.py --output offline-deploy

# 打包整个项目（含源码和文档）
python3 scripts/package_deploy.py --output deploy-package.zip
```

### 3.2 离线部署流程

```bash
# 1. 将离线包拷贝到机器狗主机（USB方式）
cp offline-deploy /mnt/usb/
cp lite3-power-inspection.zip /mnt/usb/

# 2. 在机器狗主机上解压
cd ~
mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip

# 3. 安装离线依赖（无需网络）
source venv/bin/activate
pip install --no-index --find-links=../offline-deploy/packages -r requirements.txt

# 4. 验证安装
python3 -c "import loguru, websockets, fastapi, uvicorn, pydantic; print('✅ 全部依赖安装成功')"

# 5. 启动演示
python3 scripts/demo_12min.py --mode simulation
```
