## 三、依赖必要性评估结论

### 3.1 核心结论

| 问题 | 结论 |
|------|------|
| 缺失依赖是否必须安装？ | **是，必须安装** |
| 能否通过修改代码减少依赖？ | **可以移除loguru，但收益有限** |
| 是否影响模拟模式运行？ | **不影响，只是需要先安装依赖** |
| 是否需要离线安装包？ | **竞赛现场必须准备** |

### 3.2 依赖分析

#### loguru（可选，但建议保留）

- **使用情况**: 13个源文件使用
- **可替代性**: 可用Python标准库`logging`替代
- **移除成本**: 需修改13个文件
- **建议**: **保留**（提供更好日志体验）

#### websockets + fastapi + uvicorn + pydantic（必须）

- **使用情况**: monitor_platform/server.py核心模块
- **可替代性**: 需重写整个Web服务层
- **移除成本**: 极高（影响核心功能）
- **建议**: **必须保留**

### 3.3 最小化方案（仅供参考）

如果确实需要进一步减少依赖，可考虑：

```python
# 替换loguru为标准logging
# 在src/gateway/*.py, src/perception/*.py等13个文件中：
# 将: from loguru import logger
# 改为: import logging; logger = logging.getLogger(__name__)
```

但这仅减少1个依赖（loguru），其他4个必须保留。
