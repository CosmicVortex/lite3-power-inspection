## 四、演示流程验证

### 4.1 main.py启动流程

```python
async def run_demo(mode="simulation", ws_url=None):
    # 1. 初始化组件
    udp_controller = UDPMotionController()
    ptz_controller = PtzController()
    websocket = WebSocketGateway(server_url=ws_url)
    generator = SimulationDataGenerator(mode=mode)
    body_data = RealBodyData()
    
    # 2. 连接所有模块
    udp_controller.connect()
    udp_controller.start_heartbeat()  # 启动UDP发送+接收线程
    ptz_controller.login()
    await websocket.connect()
    
    # 3. 启动后台任务
    video_task = asyncio.create_task(forward_video_streams(ws_url))
    udp_task = asyncio.create_task(_receive_udp_and_send(websocket, body_data, udp_controller))
    
    # 4. 执行演示流程
    await _demo_stand_up(udp_controller, body_data)
    await _demo_ptz_scan(ptz_controller, body_data)
    await _demo_crack_detection(generator, websocket, body_data)
    await _demo_temperature_monitor(generator, websocket, body_data)
    await _demo_move_forward(udp_controller, body_data)
    await _demo_return(udp_controller, body_data)
    await _demo_stand_down(udp_controller, body_data)
    
    # 5. 清理资源
    udp_task.cancel()
    video_task.cancel()
    await _cleanup(...)
```

### 4.2 数据流时序

| 时间 | 事件 | 数据流 |
|------|------|--------|
| 0s | 程序启动 | UDP心跳发送，WebSocket连接建立 |
| 0.1s | 起立命令 | UDP指令 → 运动主机，body_data.status="stand" |
| 0.5s | 心跳推送 | body_data.simulate_heartbeat() → WebSocket |
| 1s | UDP数据到达 | 运动主机50Hz状态包 → udp_controller.robot_state |
| 1.1s | 数据更新 | udp_controller.is_connected() → body_data.update_from_udp() |
| 1.2s | 状态广播 | WebSocket → 监测平台 → Web界面更新 |
| ... | 持续循环 | 每秒推送system_status，100ms轮询UDP |

| 问题 | 修复方案 | 提交 |

### 8.2 已知限制

| 限制 | 说明 |
|------|------|
| 视频流占用带宽 | 双路15fps约2-5Mbps |
| UDP数据接收需配置 | 运动主机需设置发送目标地址 |
| 无模型时AI模拟 | 裂缝/温度检测使用预设数据 |

### 8.3 性能建议

- **帧率调整**：如需降低带宽，修改`video_stream_forwarder.py`中`self.fps = 15`
- **心跳间隔**：默认1秒，可通过修改`main.py`中`asyncio.sleep(0.1)`调整
- **数据缓存**：断网时消息自动缓存，网络恢复后补传
