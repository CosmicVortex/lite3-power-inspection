## 二、离线部署包必要性评估

### 2.1 竞赛场景分析

| 阶段 | 网络状态 | 是否需离线包 |
|------|----------|--------------|
| 赛前准备（学校/实验室） | ✅ 有网络 | ❌ 不需要 |
| 运输途中 | ❌ 无网络 | ❌ 不需要 |
| 竞赛现场部署 | ❌ 完全断网 | ✅ **必须准备** |
| 演示运行 | ❌ 无外网 | ✅ **必须准备** |

### 2.2 结论

**建议准备离线部署包**，原因如下：

1. **竞赛现场完全断网**：比赛场地为独立内网，无法访问PyPI等外部源
2. **时间压力大**：现场部署时间有限，离线安装更快更可靠
3. **风险可控**：提前准备可避免现场突发网络问题
4. **合规要求**：竞赛通常禁止使用外部网络

## 三、离线部署包准备方案

### 3.1 准备工作（赛前3天）

在有网络的电脑（笔记本电脑或开发机）上执行：

```bash
# 1. 克隆项目（如尚未克隆）
git clone https://github.com/CosmicVortex/lite3-power-inspection.git
cd lite3-power-inspection

# 2. 准备离线Python依赖包
python3 scripts/package_offline.py --output offline-deploy

# 3. 打包完整项目（含文档）
python3 -m zipfile -c deploy-package.zip \
    --recursion *.py *.md *.txt *.yaml *.sh \
    -x __pycache__/* .git/* venv/* data/*
```

### 3.2 离线包内容清单

| 组件 | 路径 | 大小预估 | 说明 |
|------|------|----------|------|
| Python依赖包 | offline-deploy/packages/ | ~18MB | 5个缺失包的wheel文件 |
| 项目源代码 | offline-deploy/project/src/ | ~100KB | 核心代码 |
| 启动脚本 | offline-deploy/project/scripts/ | ~50KB | 所有.sh和.py脚本 |
| 配置文件 | offline-deploy/project/config/ | ~5KB | YAML配置 |
| 文档资料 | offline-deploy/project/docs/ | ~2MB | 技术文档 |
| 官方资料 | offline-deploy/project/docs/00-参考资料/ | ~15MB | 厂商手册PDF |
| **总计** | - | **~35MB** | 单文件ZIP约16MB |

### 3.3 传输到机器狗主机

```bash
# 方式一：USB设备（推荐）
cp -r offline-deploy /mnt/usb/
cp deploy-package.zip /mnt/usb/

# 方式二：SCP（临时网络）
scp -r offline-deploy/ ysc@192.168.1.103:/home/ysc/
scp deploy-package.zip ysc@192.168.1.103:/home/ysc/
```

## 四、现场部署流程（无网络环境）

### 4.1 解压与安装

```bash
# SSH登录
ssh ysc@192.168.1.103
# 密码: '

# 1. 从USB解压项目
cd ~
mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q /mnt/usb/deploy-package.zip

# 2. 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 3. 安装离线Python依赖（关键步骤）
pip install --no-index --find-links=/mnt/usb/offline-deploy/packages -r requirements.txt

# 4. 验证安装
python3 -c "import loguru, websockets, fastapi, uvicorn, pydantic; print('✅ 全部依赖安装成功')"

# 5. 创建必要目录
mkdir -p data/logs data/cache models

# 6. 设置权限
chmod +x scripts/*.sh
```

### 4.2 启动验证

```bash
# 启动监测平台（后台）
nohup python3 scripts/start_monitor.py > data/logs/monitor.log 2>&1 &

# 验证服务
curl http://192.168.1.103:8000/api/status

# 运行演示
python3 scripts/demo_12min.py --mode simulation
```

## 六、风险应对

### 6.1 备用方案

如果离线包不完整或依赖缺失：

```bash
# 手动逐个安装（备用）
pip install loguru --no-index --find-links=/mnt/usb/offline-deploy/packages
pip install websockets --no-index --find-links=/mnt/usb/offline-deploy/packages
# ... 依次安装其他包
```

### 6.2 紧急恢复

```bash
# 清理残留进程
pkill -f start_monitor.py
pkill -f demo_12min.py

# 重新激活环境
source venv/bin/activate

# 重新验证
python3 scripts/run_diagnostic.sh
```
