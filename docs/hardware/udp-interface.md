# UDP 通讯协议参考

> 来源：绝影Lite3运动主机通讯接口 V1.0.8

## 协议概述

- **传输协议**: UDP
- **字节序**: 小端字节序
- **目标端口**: 43893
- **目标IP**: 参考 Lite3_MotionSDK 第4.1节

## 指令格式

### 简单指令结构体

```c
struct CommandHead {
    uint32_t code;           // 指令码
    uint32_t paramters_size; // 指令值长度，无有效值时为0
    uint32_t type;           // 指令类型，简单指令为0
};
```

### 指令格式

```
[xxxx yyyy zzzz]
```
- xxxx: code (指令码)
- yyyy: paramters_size (参数长度)
- zzzz: type (指令类型)

## 主要指令集

### 1. 心跳指令
- 保持连接，防止超时断线

### 2. 机器人状态转换
- 上电、启动、急停、恢复等

### 3. 轴指令
- 控制各关节运动

### 4. 运动模式切换
- 平地模式、越障模式等

### 5. 步态切换
- 不同步态控制

### 6. AI功能指令
- 识别跟随、停障、绕障等

## 状态上报

运动主机默认只向感知主机上报数据。如需接收，需通过SSH连接运动主机修改发送目标地址。

### 机器人状态信息
- 位置、速度、姿态
- 电池状态
- 关节角度、速度、力矩

### 关节信息
- 各关节当前状态
- 温度、电流等

## 注意事项

1. 开发主机需设置静态IP
2. 心跳需保持周期性发送
3. 指令参数需符合协议格式
4. 紧急情况使用急停指令
