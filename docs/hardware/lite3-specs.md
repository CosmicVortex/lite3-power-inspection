# 绝影Lite3 专业版规格参数

> 来源：绝影Lite3专业版产品手册 V2.0.0

## 基本信息

| 项目 | 参数 |
|------|------|
| 产品名称 | 绝影Lite3 专业版 |
| 自由度 | 12 |
| 工作尺寸 | 610mm × 370mm × 445mm |
| 站立尺寸 | 610mm × 370mm × 503mm |
| 重量 | 7kg (不含电池) |
| 续航时间 | 1.5~2小时 |
| 续航里程 | 3.4km |
| 最大负载 | 5kg |
| 越障高度 | 15cm |
| 爬坡角度 | 40° |

## 硬件接口

- **以太网口**: Ethernet
- **USB**: Type-C, USB3.0
- **视频输出**: HDMI
- **电源输入**: 5V/24V 外接电源

## 感知能力

| 型号 | 感知功能 |
|------|----------|
| 体验版 | 前后停障、识别跟随 |
| 探索版 | 前后停障、识别跟随 |
| 专业版 | 前后停障、识别跟随、前向绕障 |
| 激光版 | 前后停障、识别跟随、前向绕障、自主导航 |

## 二次开发接口

- 运动控制算法开发SDK
- 感知例程源码
- 通信协议 (UDP)
- ROS支持

## 坐标系定义

### 身体坐标系
- 原点：机器狗身体几何中心

### 关节坐标系
- FL_HipX (红): X=0.1745, Y=0.062, Z=0
- FL_HipY (黄): X=0, Y=0.0985, Z=0
- FL_Knee (蓝): X=0, Y=0, Z=-0.20
- FL_Foot (绿): X=0, Y=0, Z=-0.21

## 运动能力

- 支持跳越沟壑、跳高、前空翻等高难度动作
- 可攀爬15cm台阶
- 支持后空翻、扭身体、扭身跳、打招呼、太空步、翻身爬起等动作
- 极限行走负载7.5kg (专业版提升40%)
