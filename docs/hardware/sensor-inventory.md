# 传感器配置清单

## 核心传感器

### 绝影Lite3 内置传感器

| 传感器 | 型号 | 参数 | 用途 |
|--------|------|------|------|
| 广角可见光相机 | 内置 | 120°FOV, 1080p | 环境感知、裂缝检测 |
| 深度相机 | 内置 | RGB-D, 1m range | 距离测量、避障 |
| 超声波雷达 | 内置 | 4个方向 | 近距离停障 |
| IMU | 内置 | 9轴 | 姿态估计、定位 |
| 编码器 | 内置 | 12个关节 | 关节状态反馈 |

### 上装传感器

| 传感器 | 型号/规格 | 参数 | 用途 | 数量 |
|--------|-----------|------|------|------|
| 高清可见光相机 | 可选: Hikvision/海康 | 4K, 30fps, HDR | 裂缝检测增强 | 1 |
| 红外热像仪 | 可选: FLIR/高德纳 | 640×512, -20~150℃ | 温度监测 | 1 |
| 补光灯 | LED环形灯 | 可调亮度 | 暗光环境补光 | 1 |

## 传感器安装方案

### 安装位置
```
        ┌─────────────┐
        │   红外热像仪  │  ← 顶部安装，朝下45°
        ├─────────────┤
        │  高清可见光  │  ← 前部安装，朝前
        │     相机     │
        ├─────────────┤
        │   机器狗头部  │
        │  (内置相机)  │
        └─────────────┘
```

### 固定方式
- 3D打印定制支架
- VESA标准接口（75×75mm）
- 减震硅胶垫
- 线缆卡扣固定

## 电源管理

### 供电方案
```
24V (机器狗主电源)
    │
    ├─→ 24V→12V 降压模块 ──→ 补光灯
    │
    ├─→ 24V→5V 降压模块 ──→ 可见光相机
    │
    └─→ 24V→5V 降压模块 ──→ 红外热像仪
```

### 功耗估算
| 设备 | 功率 | 工作电流(5V) |
|------|------|--------------|
| 可见光相机 | 5W | 1.0A |
| 红外热像仪 | 8W | 1.6A |
| 补光灯 | 10W | 2.0A |
| **总计** | **23W** | **4.6A** |

### 电池续航影响
- 空载续航: 1.5~2小时
- 满载续航: 约1小时（增加上装后）
- 建议: 准备备用电池

## 通信接口

### 数据接口
| 传感器 | 接口类型 | 带宽需求 |
|--------|----------|----------|
| 可见光相机 | USB 3.0 | 5Gbps |
| 红外热像仪 | USB 3.0 / Gigabit | 2Gbps |
| 补光灯 | GPIO / PWM | 低 |

### 网络需求
- 带宽: ≥100Mbps（视频流）
- 延迟: <100ms
- 稳定性: Wi-Fi 5GHz 或有线以太网
