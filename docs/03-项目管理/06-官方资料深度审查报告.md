## 三、开发流程核实

### 3.1 感知主机开发流程

根据官方《感知开发手册V2.2.3》，标准开发流程如下：

```
┌─────────────────────────────────────────────────────────────┐
│                    感知主机开发流程                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 环境准备                                                │
│     ├─ 安装Ubuntu 20.04 LTS + JetPack 4.6                   │
│     ├─ 配置Python 3.8环境                                   │
│     └─ 安装TensorRT 8.x                                     │
│                                                             │
│  2. 通信配置                                                │
│     ├─ 配置静态IP: 192.168.1.120                            │
│     ├─ 连接运动主机UDP服务 (192.168.1.103:43893)            │
│     └─ 配置WebSocket上报服务 (192.168.1.200:8765)           │
│                                                             │
│  3. 视觉算法开发                                            │
│     ├─ 加载YOLOv8模型 (.pt → .onnx → .trt)                 │
│     ├─ 实现图像预处理（缩放、归一化）                         │
│     ├─ 执行推理并解析输出                                    │
│     └─ 应用后处理（NMS、坐标还原）                           │
│                                                             │
│  4. 数据上报                                                │
│     ├─ 格式化检测结果JSON                                   │
│     ├─ 通过WebSocket上报至监测平台                           │
│     └─ 断网时缓存至SQLite数据库                              │
│                                                             │
│  5. 联调测试                                                │
│     ├─ 单元测试：各模块独立测试                              │
│     ├─ 集成测试：全流程联调                                  │
│     └─ 压力测试：长时间运行稳定性                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**代码实现状态**：
- ✅ 阶段1-2：已完成环境配置和通信配置
- ⚠️ 阶段3：框架已搭建，需模型文件完成推理
- ✅ 阶段4：WebSocket和SQLite缓存已实现
- ⏳ 阶段5：待硬件到位后联调

### 3.2 云台控制开发流程

根据官方《数尔安防软件开发协议V1.0》和Demo代码，标准开发流程如下：

```
┌─────────────────────────────────────────────────────────────┐
│                    云台控制开发流程                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 网络连接                                                │
│     ├─ 配置云台静态IP: 192.168.1.108                        │
│     ├─ 验证HTTP服务可达性                                   │
│     └─ 测试RTSP流地址                                       │
│                                                             │
│  2. Session管理                                             │
│     ├─ 调用Login.cgi获取Session Token                       │
│     ├─ 定期发送Heartbeat.cgi保持Session活跃                   │
│     └─ 使用完毕后调用Logout.cgi登出                          │
│                                                             │
│  3. 角度控制                                                │
│     ├─ 调用SetPtzangle.cgi设置角度                           │
│     ├─ 偏航角范围: -180° ~ 180°                             │
│     ├─ 俯仰角范围: -115° ~ 40°                              │
│     └─ 翻滚角范围: -30° ~ 30°                               │
│                                                             │
│  4. 变焦控制                                                │
│     ├─ 调用ZoomCtrl.cgi设置变倍级别 (1-10)                   │
│     └─ 10×光学变焦用于精细检测                               │
│                                                             │
│  5. 快照拍摄                                                │
│     ├─ 调用Snapshot.cgi拍摄快照                             │
│     └─ 快照URL: http://192.168.1.108:8080/snap/{id}.jpg    │
│                                                             │
│  6. RTSP视频流                                              │
│     ├─ 可见光主码流: /id=1&type=0                           │
│     ├─ 可见光辅码流: /id=1&type=1                           │
│     └─ 热成像码流: /id=2&type=0                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**代码实现状态**：
- ✅ 所有接口已完整实现
- ✅ 符合MerlinSession协议规范
- ✅ 支持自动心跳保活
