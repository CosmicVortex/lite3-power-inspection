## 评分维度

| 维度 | 分值 | 关键指标 |
|------|------|----------|
| 功能完整性 | 25分 | 裂缝检测率≥90%，温度准确率≥95% |
| 演示表现 | 20分 | 12分钟流程完整，操作流畅 |
| 技术创新 | 15分 | 算法优化、系统集成 |
| 代码质量 | 15分 | 规范、文档、可扩展性 |
| 稳定性 | 15分 | 连续运行≥1.5h，断网容错 |
| 团队协作 | 5分 | 分工明确、配合默契 |
| 加分项 | 5分 | 夜间演示、自定义路径 |

---

## 技术指标要求

| 指标 | 目标值 |
|------|--------|
| 裂缝检测率 | ≥90% |
| 温度监测准确率 | ≥95% |
| 端到端时延 | ≤2s |
| 告警响应时间 | ≤500ms |
| 连续运行时间 | ≥1.5h |
