# 项目概述

> **项目名称**: 绝影Lite3电力巡检演示系统  
> **应用背景**: 广西电力职院机器狗电力巡检国赛  
> **版本**: V1.0

---

## 一、项目背景

随着智能电网建设的推进，电力巡检自动化成为重要发展方向。四足机器人凭借其地形适应性，在复杂电力环境巡检中具有独特优势。本项目基于云深处科技绝影Lite3专业版机器狗和数尔安防双光谱云台相机，开发抽水蓄能电站场景下的机器狗移动巡检方案。

## 二、演示目标

| 指标 | 目标值 |
|------|--------|
| 演示时长 | 约 12 分钟 |
| 裂缝检测阈值 | ≥0.1mm |
| 测量精度 | 亚像素级（0.05px） |
| 温度告警阈值 | 45℃(WARN) / 50℃(CRITICAL) |
| 端到端时延 | ≤2s |
| 连续运行时间 | ≥1.5h |

## 三、系统组成

```
绝影Lite3 ──▶ 双光谱云台 ──▶ 监测平台(第三方)
   │              │
   ├── Jetson NX  ├── 8MP可见光
   ├── WiFi       ├── 640×512红外
   └── 运动控制   └── 三轴增稳
```

## 四、本项目范围

### ✅ 包含内容
1. 上装系统集成（云台安装、支架设计、电源适配）
2. 数据采集与处理（裂缝检测算法、温度监测、告警生成）
3. 通信协议对接（数尔WEB2.0、WebSocket、RTSP）
4. 与第三方平台对接（Mock Server、接口文档）

### ❌ 不包含内容
- 监测平台开发（第三方负责）
- 沙盘模型制作（现场搭建）
- 机器狗本体硬件改造
