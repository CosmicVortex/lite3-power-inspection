## 一、项目背景

随着智能电网建设的推进，电力巡检自动化成为重要发展方向。四足机器人凭借其地形适应性，在复杂电力环境巡检中具有独特优势。本项目基于云深处科技绝影Lite3专业版机器狗和数尔安防双光谱云台相机，开发抽水蓄能电站场景下的机器狗移动巡检方案。

## 二、演示要求

### 演示时长
- **总时长**: 约 12 分钟
- **包含**: 系统介绍 + 现场演示 + 数据汇报 + 答辩

### 演示场景

#### 场景一：混凝土裂缝视觉检测
- 机器狗搭载双光谱云台相机（800万像素 + 10倍光学变焦 + 三轴增稳）
- 对混凝土结构进行巡检，自动识别 **0.1mm 及以上裂缝**
- 自动识别**表面蜂窝麻面**缺陷
- 定位缺陷位置并告警，将检测数据实时上传至运维平台

#### 场景二：大体积混凝土温度监测
- 机器狗搭载红外热成像组件（640×512，测温-20~150℃）
- 实时监测温度分布
- **双级温度告警**：
  - 温度超过 **45℃** → 发出预警（WARN，黄色）
  - 温度高于 **50℃** → 发出告警（CRITICAL，红色）

## 三、系统组成

```
绝影Lite3 ──▶ 双光谱云台 ──▶ 监测平台(第三方)
   │              │
   ├── Jetson NX  ├── 8MP可见光
   ├── WiFi       ├── 640×512红外
   └── 运动控制   └── 三轴增稳
```

## 四、本项目范围

### ✅ 包含内容
1. 上装系统集成（云台安装、支架设计、电源适配）
2. 数据采集与处理（裂缝检测算法、温度监测、告警生成）
3. 通信协议对接（数尔WEB2.0、WebSocket、RTSP）
4. 与第三方平台对接（Mock Server、接口文档）

### ❌ 不包含内容
- 监测平台开发（第三方负责）
- 沙盘模型制作（现场搭建）
- 机器狗本体硬件改造
