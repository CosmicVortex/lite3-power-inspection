## 加工件设计要求

### 安装转接支架
```
设计要求：
1. 适配 Lite3 背部 M6 螺纹接口
2. 适配双光谱云台相机底座
3. 高度适中，不影响机器狗运动
4. 稳固可靠，加装橡胶减震垫
5. 方便拆装维护

参考尺寸：
- Lite3 背部接口：标准 M6 螺纹孔
- 云台相机底座：M6 安装孔
- 建议高度：50-80mm
- 总重量：< 350g
```

### 上装外护罩
```
设计要求：
1. 保护相机免受碰撞
2. 良好的散热设计（云台功耗≤11W）
3. 轻量化（< 500g）
4. 便于快速拆装
5. 与 Lite3 外观协调

材料建议：
- PLA/ABS 3D打印
- 或 亚克力切割组装
```
