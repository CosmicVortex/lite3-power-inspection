### 1.3 环境变量配置

创建 `~/.inspection_env` 文件：

```bash
# 项目路径
export PROJECT_HOME=~/lite3-power-inspection

# Python路径
export PYTHONPATH=${PROJECT_HOME}/src:${PYTHONPATH}

# 模型路径
export MODEL_PATH=${PROJECT_HOME}/models

# 日志路径
export LOG_PATH=${PROJECT_HOME}/data/logs
```

在 `~/.bashrc` 中添加：
```bash
source ~/.inspection_env
```

## 二、运动主机说明

| 项目 | 说明 |
|------|------|
| 主机型号 | RK3588 ARM处理器 |
| IP地址 | 192.168.1.103（与感知主机共享） |
| 部署需求 | **无需单独部署**，通过UDP协议(端口43893)与感知主机通信 |
| 主要职责 | 运动控制、步态规划、实时通信 |

> **重要说明**：绝影Lite3为单机双主机架构，感知主机与运动主机共享同一IP地址 `192.168.1.103`，通过不同端口区分服务（UDP 43893 / WebSocket 8765 / RTSP 554）。运动控制功能由绝影官方SDK提供，本项目仅需通过UDP协议与之通信。

## 四、网络配置

### 4.1 IP地址规划

| 设备 | IP地址 | 端口 | 服务 |
|------|--------|------|------|
| 感知主机 | 192.168.1.103 | 43893 | UDP运动控制 |
