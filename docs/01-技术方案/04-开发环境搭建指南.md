## 二、开发环境安装

### 2.1 克隆仓库

```bash
git clone https://github.com/CosmicVortex/lite3-power-inspection.git
cd lite3-power-inspection
```

### 2.2 创建虚拟环境

```bash
# 使用venv
python3 -m venv venv
source venv/bin/activate

# 或使用conda
conda create -n inspection python=3.9
conda activate inspection
```

### 2.3 安装Python依赖

```bash
# 核心依赖
pip install -r requirements/core.txt

# 视觉算法依赖
pip install -r requirements/perception.txt

# 通信依赖
pip install -r requirements/gateway.txt

# 开发依赖
pip install -r requirements/dev.txt
```

### 2.4 安装系统依赖

```bash
# Ubuntu 20.04
sudo apt-get update
sudo apt-get install -y \
    ros-foxy-desktop \
    ros-foxy-nav2-bringup \
    ros-foxy-vision-msgs \
    librealsense2-utils \
    libusb-1.0-0-dev \
    pkg-config \
    cmake \
    git \
    curl \
    wget
```

### 2.5 安装TensorRT

```bash
# 下载TensorRT (从NVIDIA官网)
wget https://developer.nvidia.com/downloads/compute/machine-learning/tensorrt/secure/8.x/packages/...

# 解压安装
tar -xzf TensorRT-8.x.x.x.tar.gz
export TENSORRT_PATH=$(pwd)/TensorRT-8.x.x.x
export LD_LIBRARY_PATH=${TENSORRT_PATH}/lib:$LD_LIBRARY_PATH
```

## 三、ROS2工作空间配置

### 3.1 创建工作空间

```bash
mkdir -p ~/inspection_ws/src
cd ~/inspection_ws
```

### 3.2 克隆ROS2包

```bash
cd src
git clone https://github.com/CosmicVortex/lite3-ros2-packages.git
```

### 3.3 编译工作空间

```bash
cd ..
source /opt/ros/foxy/setup.bash
colcon build --symlink-install
source install/setup.bash
```

## 五、模型部署

### 5.1 YOLOv8模型转换

```bash
# 1. 导出ONNX模型
yolo export model=yolov8s.pt format=onnx opset=11

# 2. 转换为TensorRT引擎
trtexec --onnx=yolov8s.onnx \
        --saveEngine=yolov8s.trt \
        --fp16 \
        --workspace=1024 \
        --minTiming=100 \
        --iter=1000 \
        --timeout=300
```

### 5.2 U-Net模型转换

```bash
# 1. 导出ONNX模型
python export_onnx.py --model unet-crack.pt --output unet-crack.onnx

# 2. 转换为TensorRT引擎
trtexec --onnx=unet-crack.onnx \
        --saveEngine=unet-crack.trt \
        --fp16 \
        --workspace=512
```

### 5.3 模型验证

```python
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoprimaryctx

# 加载引擎
logger = trt.Logger(trt.Logger.WARNING)
with open("yolov8s.trt", "rb") as f:
    engine = trt.Runtime(logger).deserialize_cuda_engine(f.read())

# 验证推理
context = engine.create_execution_context()
print(f"Engine loaded successfully")
print(f"Input bindings: {engine.num_inputs}")
print(f"Output bindings: {engine.num_outputs}")
```

## 六、常见问题

### 6.1 TensorRT导入失败

```bash
# 检查CUDA版本
nvcc --version

# 检查TensorRT版本
python -c "import tensorrt; print(tensorrt.__version__)"

# 重新安装
pip uninstall tensorrt
pip install tensorrt==8.x.x.x
```

### 6.2 ROS2节点启动失败

```bash
# 检查ROS2环境
source /opt/ros/foxy/setup.bash
echo $ROS_DOMAIN_ID

# 检查节点列表
ros2 node list
ros2 topic list
```

### 6.3 视频流无法拉取

```bash
# 检查网络
ping 192.168.1.108

# 检查RTSP端口
nc -zv 192.168.1.108 554

# 使用ffprobe测试
ffprobe rtsp://admin:123456@192.168.1.108:554/id=1&type=0
```
