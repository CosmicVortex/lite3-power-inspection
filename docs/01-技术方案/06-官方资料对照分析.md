## 三、发现的新接口

官方示例代码中包含以下未在技术文档中详述的接口：

### 3.1 方向控制接口

```http
POST /merlin/SetPtzDirection.cgi HTTP/1.1
Host: 192.168.1.108
Content-Type: application/json
Cookie: MerlinSession=abc123xyz

{
  "Direction": {
    "ptz_opt": "up",
    "speed": 20
  }
}
```

**支持的方向参数**：
- `left-up`, `right-down`, `left-down`, `right-up`
- `left`, `right`, `up`, `down`, `stop`

### 3.2 电机使能接口

```http
POST /merlin/SetPtzAbility.cgi HTTP/1.1
Host: 192.168.1.108
Content-Type: application/json
Cookie: MerlinSession=abc123xyz

{
  "Motor": {
    "Enable": 2
  }
}
```

**Enable参数说明**：
- `0`: 关闭电机
- `1`: 启动电机
- `2`: 重启电机

### 3.3 云台控制接口（PtzCtrl）

```http
GET /merlin/PtzCtrl.cgi?Operation=2&Speed=20 HTTP/1.1
Host: 192.168.1.108
```

**操作码说明**：
| 值 | 说明 |
|----|------|
| 0 | 停止云台操作 |
| 1 | 左上 |
| 2 | 上 |
| 3 | 右上 |
| 4 | 左 |
| 5 | 右 |
| 6 | 左下 |
| 7 | 下 |
| 8 | 右下 |
| 9 | 变倍+ |
| 10 | 变倍- |
| 11 | 变焦+ |
| 12 | 变焦- |
| 13 | 光圈+ |
| 14 | 光圈- |
| 20 | 转到预置点 |

## 四、注意事项

### 4.1 代理设置
官方示例代码中强制禁用了代理：
```python
os.environ['no_proxy'] = '*'
```

### 4.2 并发限制
同一云台实例最多支持3个并发连接。

### 4.3 角度限制
- 偏航角 yaw: -180° ~ 180°
- 俯仰角 pitch: -115° ~ 40°
- 翻滚角 roll: -30° ~ 30°
