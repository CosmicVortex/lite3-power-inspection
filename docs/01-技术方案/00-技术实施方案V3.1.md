## 一、项目概述

### 1.1 项目背景

智能电网建设推动电力巡检自动化发展。四足机器人在复杂地形环境下具备传统轮式平台无法比拟的地形适应性，适用于抽水蓄能电站等电力设施的巡检任务。本项目基于云深处科技绝影Lite3专业版四足机器人平台和数尔安防双光谱云台相机，开发面向竞赛演示的机器狗电力巡检系统，实现混凝土裂缝视觉检测与大体积混凝土温度监测两大核心功能。

### 1.2 演示目标

| 序号 | 指标项 | 目标值 | 验收标准 |
|------|--------|--------|----------|
| 1 | 演示时长 | 12分钟 | 完整执行演示脚本 |
| 2 | 裂缝检测阈值 | ≥0.1mm | 测试集检出率≥90% |
| 3 | 测量精度 | 0.05px（亚像素） | 宽度测量误差<0.02mm |
| 4 | 温度告警阈值 | 45℃(WARN)/50℃(CRITICAL) | 误报率<5% |
| 5 | 端到端时延 | ≤2s | 从检测到上报的时间间隔 |
| 6 | 连续运行时间 | ≥1.5h | 满载工况下电池续航 |

### 3.3 运动控制系统

**UDP通信协议实现规范**：

根据《运动主机通讯接口V1.0.8》，运动控制采用UDP协议，通信参数如下：

| 通信参数 | 值 | 说明 |
|----------|-----|------|
| 目标端口 | 43893 | 运动控制服务端口 |
| 字节序 | 小端序(Little-Endian) | 多字节整数按低位在前排列 |
| 心跳频率 | ≥2Hz | 低于此频率机器人判定为通信超时 |
| 数据包大小 | ≤268字节 | 简单指令12字节，复杂指令最大268字节 |

**指令格式规范**：

**简单指令**（无载荷）：
```
[指令码:4B][指令值:4B][指令类型:4B] = 12字节
```
- 指令码(uint32_t)：操作码，标识指令功能
- 指令值(uint32_t)：附加参数，无意义时置0
- 指令类型(uint32_t)：0=简单指令，1=复杂指令

**复杂指令**（带载荷）：
```
[指令码:4B][指令值:4B][指令类型:4B][载荷数据:N×1B] = 12+N字节
```
- 载荷数据最长256字节，按具体指令格式填充

**核心指令码定义**：

| 指令名称 | 指令码(十六进制) | 指令值 | 用途说明 |
|----------|------------------|--------|----------|
| 心跳包 | 0x21040001 | 0 | 维持通信链路，周期≤500ms |
| 起立 | 0x21010202 | 0 | 从趴下状态切换到站立 |
| 趴下 | 0x21010202 | 1 | 从站立状态切换到趴下 |
| 软急停 | 0x21020C0E | 0 | 紧急停止所有运动，可恢复 |
| 硬急停 | 0x21020C0F | 0 | 立即切断电机动力 |
| 回零 | 0x21010C05 | 0 | 将所有关节回归零位 |
| 进入AI模式 | 0x21010528 | 0 | 允许外部程序控制运动 |
| 退出AI模式 | 0x2101052B | 0 | 切换回自主模式 |

**速度控制指令格式**：

| 偏移 | 字段 | 类型 | 范围 | 单位 | 说明 |
|------|------|------|------|------|------|
| 0 | vx | float32 | -1.0~1.0 | m/s | 前后速度，正=前 |
| 4 | vy | float32 | -1.0~1.0 | m/s | 左右速度，正=左 |
| 8 | vw | float32 | -1.0~1.0 | rad/s | 旋转速度，正=逆时针 |

**Python实现示例**：

```python
import socket
import struct
import threading
import time
from typing import Optional, Tuple

class MotionController:
    """绝影Lite3运动控制UDP客户端
    
    封装与运动主机(RK3588)的UDP通信，提供运动控制接口。
    """
    
    # 指令码定义
    CMD_HEARTBEAT = 0x21040001
    CMD_STAND_UP = 0x21010202
    CMD_SIT_DOWN = 0x21010203  # 趴下
    CMD_EMERGENCY_STOP = 0x21020C0E
    CMD_HOME = 0x21010C05
    CMD_ENTER_AI = 0x21010528
    CMD_EXIT_AI = 0x2101052B
    
    # 速度指令码
    CMD_VELOCITY = 0x0103
    
    def __init__(self, robot_ip: str = "192.168.1.103", port: int = 43893):
        """初始化运动控制器
        
        Args:
            robot_ip: 运动主机IP地址
            port: UDP通信端口
        """
        self.target_addr = (robot_ip, port)
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self.sock.settimeout(1.0)  # 1秒超时
        self._heartbeat_thread: Optional[threading.Thread] = None
        self._running = False
        
    def start_heartbeat(self, interval: float = 0.4):
        """启动心跳线程，保持与运动主机通信
        
        Args:
            interval: 心跳间隔(秒)，默认400ms
        """
        self._running = True
        self._heartbeat_thread = threading.Thread(
            target=self._heartbeat_loop, 
            args=(interval,),
            daemon=True
        )
        self._heartbeat_thread.start()
        
    def _heartbeat_loop(self, interval: float):
        """心跳循环执行"""
        while self._running:
            self.send_heartbeat()
            time.sleep(interval)
            
    def send_heartbeat(self):
        """发送心跳包"""
        self._send_simple_cmd(self.CMD_HEARTBEAT)
        
    def _send_simple_cmd(self, code: int):
        """发送简单指令（无载荷）"""
        data = struct.pack('<III', code, 0, 0)
        self.sock.sendto(data, self.target_addr)
        
    def set_velocity(self, vx: float, vy: float, vw: float):
        """设置运动速度
        
        Args:
            vx: 前后速度 (m/s)
            vy: 左右速度 (m/s)
            vw: 旋转速度 (rad/s)
        """
        data = struct.pack('<IIIfff', self.CMD_VELOCITY, 0, 0, vx, vy, vw)
        self.sock.sendto(data, self.target_addr)
        
    def stand_up(self):
        """机器人起立"""
        self._send_simple_cmd(self.CMD_STAND_UP)
        
    def sit_down(self):
        """机器人趴下"""
        self._send_simple_cmd(self.CMD_SIT_DOWN)
        
    def emergency_stop(self):
        """软急停"""
        self._send_simple_cmd(self.CMD_EMERGENCY_STOP)
        
    def enter_ai_mode(self):
        """进入AI控制模式"""
        self._send_simple_cmd(self.CMD_ENTER_AI)
        
    def exit_ai_mode(self):
        """退出AI控制模式"""
        self._send_simple_cmd(self.CMD_EXIT_AI)
        
    def stop(self):
        """停止心跳线程"""
        self._running = False
        if self._heartbeat_thread:
            self._heartbeat_thread.join(timeout=2.0)
        self.sock.close()
```

## 四、视觉检测算法

### 4.1 裂缝检测算法设计

**算法架构：两阶段级联检测**

```
┌─────────────────────────────────────────────────────────────┐
│  阶段一：广角巡检发现（YOLOv8-s）                            │
├─────────────────────────────────────────────────────────────┤
│  输入: 可见光主码流 RTSP（1×变焦，5Hz抽帧）                   │
│     ↓                                                       │
│  [TensorRT INT8加速] YOLOv8-s推理 ≈15ms/帧                   │
│     ↓                                                       │
│  过滤条件: confidence > 0.5 AND area > min_area              │
│     ↓                                                       │
│  触发云台动作:                                              │
│    1. ptz.zoom_ctrl(zoom=10) → 变倍到10×                    │
│    2. ptz.auto_focus() → 自动对焦                           │
│    3. sleep(0.5) → 等待云台稳定                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段二：精细分割测量（U-Net）                               │
├─────────────────────────────────────────────────────────────┤
│  输入: 10×变焦可见光图像                                    │
│     ↓                                                       │
│  [ONNX Runtime] U-Net推理 → 裂缝概率图                      │
│     ↓                                                       │
│  后处理:                                                    │
│    1. 阈值二值化(p>0.5)                                     │
│    2. 形态学开运算去噪                                      │
│    3. 骨架提取(细化为单像素宽)                               │
│    4. 距离变换计算宽度                                      │
│     ↓                                                       │
│  亚像素测量:                                                │
│    方法: 灰度矩法，精度0.05px                                │
│    换算: 0.019mm/px × 0.05px = 0.00095mm ≈ 1μm             │
│     ↓                                                       │
│  输出:                                                      │
│    - 裂缝中心坐标(px, py)                                   │
│    - 裂缝宽度(mm)，精度±0.02mm                              │
│    - 裂缝长度(mm)                                           │
│    - 置信度                                                 │
│    - 缺陷类型(裂缝/蜂窝麻面)                                │
└─────────────────────────────────────────────────────────────┘
```

**精度校核计算**：

| 阶段 | 工作距离 | 变焦倍数 | 水平视场角 | 水平视野 | 像素精度 | 适用场景 |
|------|----------|----------|-----------|----------|----------|----------|
| 广角巡检 | 300mm | 1×(3.2mm) | 90.3° | ≈603mm | 6.37μm/px | 大范围扫描 |
| 精细检测 | 200mm | 10×(32mm) | 20.4° | ≈72mm | 0.19μm/px | 精确测量 |

**精度结论**：精细检测阶段像素精度约0.019mm/px，0.1mm裂缝占据约5.3像素，配合亚像素细分(0.05px)可达到测量精度要求。

### 4.2 温度监测算法设计

**算法流程**：

```
┌─────────────────────────────────────────────────────────────┐
│  温度监测算法                                                │
├─────────────────────────────────────────────────────────────┤
│  输入: 热成像RTSP流(id=2&type=0)，分辨率640×512             │
│     ↓                                                       │
│  1. ROI区域提取：根据预设坐标框选监测区域                     │
│     ↓                                                       │
│  2. 温度数据解析：从热成像帧中提取ROI内像素温度值             │
│     ↓                                                       │
│  3. 滑动平均滤波：窗口大小=3帧，抑制瞬时噪声                  │
│     ↓                                                       │
│  4. 温度统计：计算ROI内max/avg/min温度                       │
│     ↓                                                       │
│  5. 双级告警判定：                                         │
│     ├─ if temp_max >= 50℃: 触发CRITICAL告警                │
│     ├─ elif temp_max >= 45℃: 触发WARN预警                  │
│     └─ else: 正常状态                                      │
│     ↓                                                       │
│  6. 去抖机制：                                             │
│     - WARN确认：连续5帧(100ms)满足阈值才触发                 │
│     - CRITICAL确认：连续3帧(60ms)满足阈值立即触发            │
│     - 状态保持：CRITICAL触发后，回落至45~50℃仍保持30s       │
│     ↓                                                       │
│  输出: 告警事件+联动沙盘灯带                                │
└─────────────────────────────────────────────────────────────┘
```

**告警逻辑状态机**：

```
          ┌─────────────────────────────────────┐
          │           正常状态(NORMAL)           │
          │  temp < 45℃，无告警输出              │
          └──────────────┬──────────────────────┘
                         │ temp ≥ 45℃ (连续5帧)
                         ▼
          ┌─────────────────────────────────────┐
          │           预警状态(WARN)             │
          │  黄色指示灯亮起                      │
          │  上报WARN事件到监测平台              │
          └──────────────┬──────────────────────┘
                         │ temp ≥ 50℃ (连续3帧)
                         ▼
          ┌─────────────────────────────────────┐
          │         告警状态(CRITICAL)           │
          │  红色指示灯亮起+蜂鸣器               │
          │  联动沙盘降温装置                    │
          │  上报CRITICAL事件到监测平台          │
          └──────────────┬──────────────────────┘
                         │ temp < 45℃ (持续30s)
                         ▼
          （回到正常状态）
```

| 步骤 | API端点 | 请求方法 | 认证方式 | 响应 |
|------|---------|----------|----------|------|

**登录认证流程**：
1. 客户端使用Basic Auth发送登录请求（账号密码：admin/123456）
2. 服务端验证通过后返回MerlinSession Cookie，有效期30秒
3. 客户端需在30秒内发送第一次心跳，之后每10秒发送一次心跳维持会话
4. 超时无心跳则Session失效，需重新登录

**云台控制接口**：

| 操作 | API端点 | 请求方式 | 参数格式 | 说明 |
|------|---------|----------|----------|------|
| 角度控制 | /SetPtzangle.cgi | POST | JSON: {Angle:{yaw,pitch,roll}} | 绝对角度定位 |
| 变倍控制 | /ZoomCtrl.cgi | GET | query: ?zoom=N | N∈[1,10]整数 |
| 状态查询 | /GetFlyStateInfo.cgi | GET | - | 返回当前角度和变倍值 |
| 预置位调用 | /SetPreset.cgi | POST | JSON: {Id:N,Action:1/2} | 1=保存,2=调用 |

**角度参数范围**：

| 轴 | 范围 | 默认值 | 备注 |
|----|------|--------|------|
| Yaw(航向) | -280°~280° | 0° | 顺时针为正 |
| Pitch(俯仰) | -115°~40° | -30° | 向下为负 |
| Roll(横滚) | 不支持 | - | 固定为0 |

**RTSP视频流地址**：

| 流类型 | URL格式 | 用途 |
|--------|---------|------|
| 可见光主码流 | `rtsp://admin:123456@192.168.1.108:554/id=1&type=0` | 裂缝检测推理 |
| 可见光辅码流 | `rtsp://admin:123456@192.168.1.108:554/id=1&type=1` | 低带宽预览 |
| 热成像码流 | `rtsp://admin:123456@192.168.1.108:554/id=2&type=0` | 温度监测 |

**Python云台控制器实现**：

```python
import requests
import threading
import time
from typing import Optional, Dict, Any
import logging

logger = logging.getLogger(__name__)

class PTZController:
    """数尔安防双光谱云台控制器
    
    封装WEB2.0协议，提供云台角度控制、变倍控制、视频流管理等功能。
    """
    
    def __init__(self, base_url: str = "http://192.168.1.108",
                 username: str = "admin", password: str = "123456",
                 heartbeat_interval: float = 10.0):
        self.base_url = base_url.rstrip('/')
        self.session = requests.Session()
        self.session.auth = (username, password)
        self.heartbeat_interval = heartbeat_interval
        self._heartbeat_thread: Optional[threading.Thread] = None
        self._session_id: Optional[str] = None
        
    def login(self) -> bool:
        """登录获取Session
        
        Returns:
            登录成功返回True
        """
        try:
            resp = self.session.get(
                f"{self.base_url}/merlin/Login.cgi",
                params={"Type": "WEB", "Expires": "30"},
                timeout=5
            )
            if resp.status_code == 200:
                self._session_id = resp.cookies.get('MerlinSession')
                logger.info("云台登录成功")
                return True
            else:
                logger.error(f"云台登录失败: {resp.status_code}")
                return False
        except Exception as e:
            logger.error(f"云台登录异常: {e}")
            return False
            
    def start_heartbeat(self):
        """启动心跳线程维持Session"""
        self._heartbeat_thread = threading.Thread(
            target=self._heartbeat_loop, daemon=True
        )
        self._heartbeat_thread.start()
        
    def _heartbeat_loop(self):
        """心跳循环"""
        while True:
            time.sleep(self.heartbeat_interval)
            try:
                self.session.get(
                    f"{self.base_url}/merlin/Heartbeat.cgi",
                    timeout=3
                )
            except Exception as e:
                logger.warning(f"心跳发送失败: {e}")
                
    def set_angle(self, yaw: float, pitch: float, roll: float = 0.0):
        """设置云台角度
        
        Args:
            yaw: 航向角(-280~280°)
            pitch: 俯仰角(-115~40°)
            roll: 横滚角(固定为0)
        """
        # 角度范围校验
        if not (-280 <= yaw <= 280):
            raise ValueError(f"yaw超出范围: {yaw}")
        if not (-115 <= pitch <= 40):
            raise ValueError(f"pitch超出范围: {pitch}")
            
        resp = self.session.post(
            f"{self.base_url}/merlin/SetPtzangle.cgi",
            json={"Angle": {"yaw": yaw, "pitch": pitch, "roll": roll}},
            timeout=5
        )
        if resp.status_code != 200:
            raise RuntimeError(f"角度控制失败: {resp.text}")
            
    def zoom(self, level: int):
        """变倍控制
        
        Args:
            level: 变倍级别(1~10)
        """
        if not (1 <= level <= 10):
            raise ValueError(f"zoom超出范围: {level}")
            
        resp = self.session.get(
            f"{self.base_url}/merlin/ZoomCtrl.cgi",
            params={"zoom": level},
            timeout=5
        )
        if resp.status_code != 200:
            raise RuntimeError(f"变倍控制失败: {resp.text}")
            
    def get_state(self) -> Dict[str, Any]:
        """获取云台当前状态"""
        resp = self.session.get(
            f"{self.base_url}/merlin/GetFlyStateInfo.cgi",
            timeout=5
        )
        return resp.json()
        
    def close(self):
        """关闭连接"""
        if self._heartbeat_thread:
            self._heartbeat_thread.join(timeout=2.0)
        self.session.close()


class InspectionPipeline:
    """巡检流程编排器
    
    编排裂缝检测和温度监测的完整流程。
    """
    
    def __init__(self, ptz: PTZController):
        self.ptz = ptz
        self.crack_detector = CrackDetector()
        self.temp_monitor = TemperatureMonitor()
        
    def inspect_crack(self, waypoint: Waypoint):
        """执行单点裂缝检测
        
        Args:
            waypoint: 巡检航点配置
        """
        # 1. 云台转到预设角度
        self.ptz.set_angle(waypoint.ptz_yaw, waypoint.ptz_pitch)
        time.sleep(0.3)  # 等待云台稳定
        
        # 2. 广角检测
        wide_frame = self._capture_wide_frame()
        detections = self.crack_detector.detect(wide_frame)
        
        # 3. 筛选疑似缺陷
        suspect_cracks = [d for d in detections 
                         if d['confidence'] > 0.5]
        
        if not suspect_cracks:
            return
            
        # 4. 触发变焦精检
        self.ptz.zoom(10)
        time.sleep(0.5)  # 等待变焦稳定
        
        # 5. 精细测量
        zoomed_frame = self._capture_zoomed_frame()
        for crack in suspect_cracks:
            measurement = self.crack_detector.measure(
                zoomed_frame, crack['bbox']
            )
            self._report_result(waypoint.id, measurement)
            
    def monitor_temperature(self, waypoint: Waypoint):
        """执行温度监测
        
        Args:
            waypoint: 巡检航点配置
        """
        # 1. 云台转到预设角度
        self.ptz.set_angle(waypoint.ptz_yaw, waypoint.ptz_pitch)
        
        # 2. 拉取热成像流
        thermal_stream = self._open_thermal_stream()
        
        # 3. 持续监测
        while self._monitoring:
            frame = thermal_stream.read()
            if frame is None:
                continue
                
            roi_temp = self.temp_monitor.extract_roi_temp(
                frame, waypoint.roi
            )
            alert = self.temp_monitor.check_alert(roi_temp)
            
            if alert:
                self._report_alert(waypoint.id, alert)
                
        thermal_stream.release()
```
