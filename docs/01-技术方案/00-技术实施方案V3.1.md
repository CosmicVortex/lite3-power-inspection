# 技术实施方案

> **版本**: V3.1  
> **编制日期**: 2026年8月  
> **适用范围**: 广西电力职院机器狗电力巡检国赛项目

---

## 一、项目概述

### 1.1 项目背景
随着智能电网建设的推进，电力巡检自动化成为重要发展方向。四足机器人凭借其地形适应性，在复杂电力环境巡检中具有独特优势。本项目基于云深处科技绝影Lite3专业版机器狗和数尔安防双光谱云台相机，开发抽水蓄能电站场景下的机器狗移动巡检方案，服务于职业高校技能竞赛演示。

### 1.2 演示目标
- **演示时长**: 约 12 分钟
- **演示场景**: 抽水蓄能电站沙盘模型（2000×500×1200mm）
- **核心能力展示**:
  1. 混凝土裂缝及蜂窝麻面视觉检测（≥0.1mm，亚像素测量精度）
  2. 大体积混凝土温度实时监测（双级告警：45℃预警/50℃告警）
  3. 巡检数据实时上传至运维平台
  4. RTSP双路视频流实时预览（可见光+红外热成像）

### 1.3 系统组成
```
绝影Lite3机器狗 ──▶ 双光谱云台相机 ──▶ 监测平台(第三方)
        │                  │                  │
   Jetson Xavier NX     数尔安防吊舱       WebSocket推送
   (21 TOPS算力)        (3.2 TOPS内置)     RTSP视频流
```

## 三、硬件方案

### 3.1 绝影Lite3专业版

| 参数 | 规格 | 本项目应用 |
|------|------|-----------|
| 自由度 | 12 DOF | 运动控制基础 |
| AI主机 | NVIDIA Jetson Xavier NX (21 TOPS) | 视觉检测推理 |
| 接口 | 24V/12V/5V、网口、USB3.0、HDMI | 供电与数据通道 |
| WiFi | 802.11ac 5GHz，<5ms时延 | 单链路通信 |
| 续航 | 1.5~2小时（空载）→ 约1.5h（满载） | 演示时长满足 |
| 运动能力 | 斜坡40°、楼梯15cm | 满足沙盘地形 |

| 类别 | 参数 | 规格 |
|------|------|------|
| **热成像** | 分辨率 | 640×512 |
| | 光谱范围 | 8~14μm |
| | 测温范围 | -20℃~150℃ |
| | 视场角 | 48.3°(H)×38.6°(V) |
| **可见光** | 传感器 | 1/1.8" SONY CMOS |
| | 像素 | 3840×2160 (800万像素) |
| | 镜头 | 3.2~32mm (10倍光学变焦) |
| | 视场角 | 90.3°~20.4° |
| | 最低照度 | 0.002 Lux |
| **云台** | 增稳轴数 | 三轴 (航向/俯仰/横滚) |

| | 定位精度 | ±0.02° |

## 四、软件方案

### 4.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 机器人中间件 | ROS2 Foxy | 运动控制与消息通信 |
| AI推理引擎 | TensorRT 8.x | GPU加速推理 |
| 视觉算法 | YOLOv8-s + U-Net | 裂缝检测与分割 |
| 通信协议 | WebSocket + RTSP | 实时数据与视频流 |
| 数据存储 | SQLite | 本地缓存与断网续传 |
| 配置管理 | YAML | 参数化管理 |

### 4.2 算法方案

#### 裂缝检测（两阶段流程）

```
阶段一：广角巡检发现
┌──────────────────────────────────────────────┐
│ 可见光主码流 RTSP (广角端, 1×变焦)           │
│     ↓                                        │
│   抽帧 5 Hz                                  │
│     ↓                                        │
│ [YOLOv8-s] 缺陷检测（裂缝二分类）            │
│     │  TensorRT INT8, ≈15ms/帧               │
│     ↓ 置信度 > 0.5                           │
│   触发变焦指令 → ptz.zoom_ctrl(zoom=10)      │
│                云台自动对焦 (AF)             │
│                等待 500ms 稳定               │
└──────────────────────────────────────────────┘

阶段二：精细分割测量
┌──────────────────────────────────────────────┐
│ 10×变焦可见光图像                            │
│     ↓                                        │
│ [U-Net] 裂缝像素级分割                       │
│     ↓                                        │
│ 骨架提取 + 距离变换                          │
│     ↓                                        │
│ 亚像素测量（精度0.05px @ 10×变焦）          │
│ 换算: 0.019mm/px → 0.1mm分辨率              │
└──────────────────────────────────────────────┘
```

#### 温度监测（双级告警）

```
┌──────────────────────────────────────────────┐
│ 热成像RTSP流 (id=2&type=0)                   │
│     ↓                                        │
│ ROI区域温度提取                              │
│     ↓                                        │
│ 滑动平均滤波（去抖，窗口=3帧）               │
│     ↓                                        │
│ 判断逻辑:                                    │
│   if temp >= 50℃: 触发 CRITICAL 告警        │
│   elif temp >= 45℃: 触发 WARN 告警          │
│   else: 正常状态                             │
│     ↓                                        │
│ WebSocket推送 + 联动沙盘灯带               │
└──────────────────────────────────────────────┘
```

### 4.3 通信架构

```
┌─────────────────────────────────────────────────────────────┐
│                    通信接口总览                               │
├──────────────┬──────────────┬──────────────┬────────────────┤
│   协议       │   用途        │   端口/地址   │   说明        │
├──────────────┼──────────────┼──────────────┼────────────────┤
│ WebSocket    │ 实时数据上报  │ :8765/ws     │ 状态/轨迹/告警│
│ HTTP REST    │ 云台控制      │ /merlin/*   │ 角度/变倍命令  │
│ RTSP         │ 视频流推送    │ :554/id=1   │ 可见光主码流  │
│              │               │ :554/id=2   │ 热成像码流    │
│ SQLite       │ 本地缓存      │ inspection.db│ 断网续传      │
└──────────────┴──────────────┴──────────────┴────────────────┘
```

## 五、演示流程

### 5.1 12分钟详细脚本

| 时间 | 阶段 | 内容 | 关键操作 |
|------|------|------|----------|
| 0:00-1:30 | 开场 | 系统介绍 | 机器狗亮相、自我介绍 |
| 1:30-3:00 | 场景一 | 广角巡检 | 启动可见光流、YOLO检测 |
| 3:00-4:30 | 场景一 | 精检演示 | 触发变焦、U-Net分割、测量 |
| 4:30-5:30 | 场景一 | 数据上报 | 展示检测结果到平台 |
| 5:30-7:00 | 场景二 | 温度扫描 | 切换热成像流、ROI框选 |
| 7:00-8:30 | 场景二 | 告警演示 | 温度升至45℃触发预警 |
| 8:30-9:30 | 场景二 | 联动演示 | 温度升至50℃触发告警+灯带 |
| 9:30-11:00 | 总结 | 数据汇总 | 轨迹回放、检测统计 |
| 11:00-12:00 | 结束 | 致谢 | 机器狗返回起点、结束语 |

### 5.2 应急预案

| 风险点 | 预案 |
|--------|------|
| 机器狗无法启动 | 准备备用电池，3分钟内切换 |
| 云台通信中断 | 重启MerlinSession，重新登录 |
| 视频流卡顿 | 切换到辅码流或预录视频 |
| 算法检测失败 | 手动触发检测流程 |
| 网络中断 | SQLite本地缓存，网络恢复后续传 |
| 演示超时 | 精简至10分钟核心流程 |
