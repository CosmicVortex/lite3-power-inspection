## 一、项目概述

### 1.1 项目背景

随着智能电网建设的推进，电力巡检自动化成为重要发展方向。四足机器人凭借其地形适应性，在复杂电力环境巡检中具有独特优势。本项目基于云深处科技绝影Lite3专业版机器狗和数尔安防双光谱云台相机，开发抽水蓄能电站场景下的机器狗移动巡检方案，服务于职业高校技能竞赛演示。

### 1.2 演示目标

| 指标 | 目标值 |
|------|--------|
| 演示时长 | 约 12 分钟 |
| 裂缝检测阈值 | ≥0.1mm |
| 测量精度 | 亚像素级（0.05px） |
| 温度告警阈值 | 45℃(WARN) / 50℃(CRITICAL) |
| 端到端时延 | ≤2s |
| 连续运行时间 | ≥1.5h |

### 3.3 运动控制（UDP协议）

根据官方《运动主机通讯接口V1.0.8》，运动控制通过UDP协议实现：

**通信参数**：
- 目标端口：43893
- 字节序：小端序
- 心跳频率：≥2Hz

**指令格式**：

简单指令：`[xxxx yyyy zzzz]`
- xxxx: 指令码 (uint32_t)
- yyyy: 指令值 (uint32_t)，无意义时为0
- zzzz: 指令类型 (uint32_t)，简单指令为0

复杂指令：`[xxxx yyyy zzzz bbbbbbbb……]`
- bbbbbbbb……: 数据内容 (最长256字节)

**常用指令码**：

| 指令名称 | 指令码 | 说明 |
|----------|--------|------|
| 心跳 | 0x21040001 | 确认连接正常 |
| 起立/趴下 | 0x21010202 | 状态切换 |
| 软急停 | 0x21020C0E | 紧急停止 |
| 回零 | 0x21010C05 | 初始化关节 |
| 进入AI | 0x21010528 | 进入AI状态 |
| 退出AI | 0x2101052B | 退出AI状态 |

**Python UDP通信示例**：

```python
import socket
import struct

class MotionController:
    """运动主机UDP通信控制器"""
    
    def __init__(self, ip="192.168.1.103", port=43893):
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        self.target_addr = (ip, port)
        
    def send_heartbeat(self):
        """发送心跳包"""
        cmd = struct.pack('<III', 0x21040001, 0, 0)
        self.sock.sendto(cmd, self.target_addr)
        
    def send_command(self, code, param=0):
        """发送简单指令"""
        cmd = struct.pack('<III', code, param, 0)
        self.sock.sendto(cmd, self.target_addr)
        
    def stand_up(self):
        """起立"""
        self.send_command(0x21010202)
        
    def sit_down(self):
        """趴下"""
        self.send_command(0x21010202)
        
    def emergency_stop(self):
        """软急停"""
        self.send_command(0x21020C0E)
        
    def enter_ai_mode(self):
        """进入AI模式"""
        self.send_command(0x21010528)
        
    def exit_ai_mode(self):
        """退出AI模式"""
        self.send_command(0x2101052B)
```

## 四、视觉检测算法

### 4.1 裂缝检测（两阶段流程）

```
┌─────────────────────────────────────────────────────────────┐
│                    阶段一：广角巡检发现                       │
├─────────────────────────────────────────────────────────────┤
│  输入: 可见光主码流 RTSP (1×变焦, 5Hz抽帧)                  │
│     ↓                                                       │
│  [YOLOv8-s] 缺陷检测（裂缝二分类）                          │
│     │  TensorRT INT8, ≈15ms/帧                             │
│     ↓ 置信度 > 0.5                                          │
│  触发变焦指令 → ptz.zoom_ctrl(zoom=10)                      │
│              → 云台自动对焦 (AF)                            │
│              → 等待 500ms 稳定                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    阶段二：精细分割测量                       │
├─────────────────────────────────────────────────────────────┤
│  输入: 10×变焦可见光图像                                    │
│     ↓                                                       │
│  [U-Net] 裂缝像素级分割                                     │
│     ↓                                                       │
│  骨架提取 + 距离变换                                        │
│     ↓                                                       │
│  亚像素测量（精度0.05px @ 10×变焦）                         │
│  换算: 0.019mm/px → 0.1mm分辨率                            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    输出结果                                   │
├─────────────────────────────────────────────────────────────┤
│  • 裂缝位置 (图像坐标)                                      │
│  • 裂缝宽度 (mm)                                            │
│  • 裂缝长度 (mm)                                            │
│  • 置信度                                                   │
│  • 缺陷类型 (裂缝/蜂窝麻面)                                 │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 温度监测算法

```
┌─────────────────────────────────────────────────────────────┐
│                    温度监测流程                               │
├─────────────────────────────────────────────────────────────┤
│  输入: 热成像 RTSP流 (id=2&type=0)                          │
│     ↓                                                       │
│  ROI区域温度提取                                            │
│     ↓                                                       │
│  滑动平均滤波（窗口=3帧，去抖）                              │

└─────────────────────────────────────────────────────────────┘
```

## 六、演示流程设计

### 6.1 12分钟脚本

| 时间 | 阶段 | 内容 | 关键操作 |
|------|------|------|----------|
| 0:00-1:30 | 开场 | 系统介绍 | 机器狗亮相、自我介绍 |
| 1:30-3:00 | 场景一 | 广角巡检 | 启动可见光流、YOLO检测 |
| 3:00-4:30 | 场景一 | 精检演示 | 触发变焦、U-Net分割、测量 |
| 4:30-5:30 | 场景一 | 数据上报 | 展示检测结果到平台 |
| 5:30-7:00 | 场景二 | 温度扫描 | 切换热成像流、ROI框选 |
| 7:00-8:30 | 场景二 | 告警演示 | 温度升至45℃触发预警 |
| 8:30-9:30 | 场景二 | 联动演示 | 温度升至50℃触发告警+灯带 |
| 9:30-11:00 | 总结 | 数据汇总 | 轨迹回放、检测统计 |
| 11:00-12:00 | 结束 | 致谢 | 机器狗返回起点、结束语 |

### 6.2 应急预案

| 风险点 | 预案 |
|--------|------|
| 机器狗无法启动 | 准备备用电池，3分钟内切换 |
| 云台通信中断 | 重启MerlinSession，重新登录 |
| 视频流卡顿 | 切换到辅码流或预录视频 |
| 算法检测失败 | 手动触发检测流程 |
| 网络中断 | SQLite本地缓存，网络恢复后续传 |
| 演示超时 | 精简至10分钟核心流程 |
