# 监测平台搭建指南

> **目的**: 提供WebSocket数据接收与可视化界面  
> **版本**: V1.0.0  
> **日期**: 2026-08-20

---

## 一、平台功能需求

### 1.1 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 实时数据接收 | WebSocket接收巡检数据 | P0 |
| 告警展示 | 裂缝检测、温升告警实时显示 | P0 |
| 数据记录 | 历史数据持久化存储 | P1 |
| 可视化面板 | 巡检状态、设备状态展示 | P1 |
| 视频预览 | RTSP流实时查看 | P2 |

### 1.2 数据协议

**WebSocket消息格式：**

```json
{
  "type": "inspection_result",
  "timestamp": 1692518400,
  "device_id": "LITE3-001",
  "data": {
    "crack": {
      "detected": true,
      "count": 3,
      "details": [
        {
          "id": "CRACK_001",
          "location": {"x": 120, "y": 340},
          "size_mm": {"width": 0.5, "length": 12.3},
          "confidence": 0.92
        }
      ]
    },
    "temperature": {
      "status": "WARN",
      "value": 46.5,
      "max_value": 48.2,
      "roi": {"x": 200, "y": 150, "w": 50, "h": 50}
    }
  }
}
```

## 二、技术选型

### 2.1 推荐方案

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 后端框架 | FastAPI | 高性能异步框架 |
| WebSocket | websockets | Python原生实现 |
| 前端框架 | Vue 3 + Element Plus | 现代化UI |
| 数据库 | SQLite | 轻量级存储 |
| 图表库 | ECharts | 丰富的可视化组件 |

### 2.2 备选方案

- **方案B**: Flask + Flask-SocketIO（更简单）
- **方案C**: Streamlit（快速原型）

## 三、快速部署（演示用）

### 3.1 安装依赖

```bash
cd /opt/data/lite3-power-inspection
pip install -r requirements.txt
pip install fastapi uvicorn websockets sqlalchemy
```

### 3.2 启动监测平台

```bash
# 启动后端服务
python3 scripts/monitor_server.py

# 访问地址
# Web界面: http://192.168.1.200:8000
# WebSocket: ws://192.168.1.200:8765/ws
```

### 3.3 连接机器人

```bash
# 在感知主机上运行
python3 src/app/main.py --demo
```

## 五、API接口说明

### 5.1 WebSocket接口

| 端点 | 协议 | 说明 |
|------|------|------|
| `/ws` | WebSocket | 实时数据推送 |
| `/ws/status` | WebSocket | 设备状态订阅 |

### 5.2 HTTP接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/inspections` | 获取巡检记录 |
| GET | `/api/alerts` | 获取告警列表 |
| POST | `/api/alert/ack` | 确认告警 |
| GET | `/api/devices` | 设备列表 |

4. **日志位置**: `data/logs/monitor.log`
