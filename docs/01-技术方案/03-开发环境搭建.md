### 1.2 运动主机（RK3588）

| 项目 | 说明 |
|------|------|
| 主机型号 | RK3588 ARM处理器 |
| IP地址 | 192.168.1.103（与感知主机共享） |
| 部署需求 | **无需单独部署**，通过UDP协议(端口43893)与感知主机通信 |

> **说明**：绝影Lite3为单机双主机架构，感知主机与运动主机共享同一IP地址 `192.168.1.103`，通过不同端口区分服务（UDP 43893 / WebSocket 8765 / RTSP 554）。运动控制功能由绝影官方SDK提供，本项目仅需通过UDP协议与之通信。

## 三、环境安装步骤

### 3.1 克隆项目仓库

```bash
# 在有网络的环境执行
git clone https://github.com/CosmicVortex/lite3-power-inspection.git
cd lite3-power-inspection
```

### 3.2 创建Python虚拟环境

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3.3 安装Python依赖

```bash
# 安装核心依赖（必需）
pip install -r requirements.txt

# 安装GPU依赖（可选，仅真实模式需要）
# pip install -r requirements-gpu.txt
```

### 3.4 验证安装

```bash
# 验证核心依赖
python3 -c "import loguru, websockets, fastapi, uvicorn, pydantic; print('✅ 核心依赖安装成功')"

# 验证GPU环境（可选）
python3 -c "import torch; print(f'✅ PyTorch版本: {torch.__version__}'); print(f'✅ CUDA可用: {torch.cuda.is_available()}')"

# 验证OpenCV
python3 -c "import cv2; print(f'✅ OpenCV版本: {cv2.__version__}')"
```

### 6.2 端口冲突

```bash
# 查看端口占用
sudo lsof -i :8765
sudo lsof -i :8000

# 终止占用进程
pkill -f start_monitor.py
pkill -f demo_12min.py
```

### 6.3 网络连通性

```bash
# 检查网络配置
ip addr show

# 测试UDP通信（与运动主机）
python3 -c "
import socket
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.sendto(b'\x01\x00\x04\x21\x00\x00\x00\x00\x00\x00\x00\x00', ('192.168.1.103', 43893))
sock.settimeout(1.0)
try:
    data, addr = sock.recvfrom(1024)
    print(f'UDP通信正常: {data.hex()}')
except socket.timeout:
    print('UDP通信超时，检查运动主机是否在线')
"
```

## 七、离线部署准备

### 7.1 生成离线包（赛前有网络时）

```bash
# 在项目根目录执行
python3 scripts/package_offline.py --output offline-deploy
```

生成的目录结构：
```
offline-deploy/
├── packages/              # Python依赖wheel包
│   ├── loguru-xxx.whl
│   ├── websockets-xxx.whl
│   ├── fastapi-xxx.whl
│   ├── uvicorn-xxx.whl
│   └── pydantic-xxx.whl
└── README.md
```

### 7.2 离线部署流程（无网络时）

```bash
# 1. 从USB解压项目
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q /mnt/usb/lite3-power-inspection.zip

# 2. 创建虚拟环境并安装依赖
python3 -m venv venv && source venv/bin/activate
pip install --no-index --find-links=/mnt/usb/offline-deploy/packages -r requirements.txt

# 3. 验证安装
python3 -c "import loguru, websockets, fastapi, uvicorn, pydantic; print('✅ 全部依赖安装成功')"

# 4. 启动系统
python3 scripts/demo_12min.py --mode simulation
```
