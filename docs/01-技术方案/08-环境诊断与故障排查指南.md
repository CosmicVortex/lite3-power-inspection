| 检查项 | 说明 |
|--------|------|
| Python版本 | 是否 >= 3.8 |
| 虚拟环境 | 是否存在 |
| Python依赖 | loguru, websockets, fastapi等是否安装 |
| GPU环境 | CUDA、PyTorch是否可用 |
| 网络连接 | 各设备端口是否可达 |
| 配置文件 | inspection_config.yaml是否存在 |
| 项目结构 | 必要目录和文件是否完整 |

## 三、标准解决方案

### 3.1 安装缺失依赖

```bash
# 方法一：网络安装（有网络时）
pip install -r requirements.txt

# 方法二：使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 方法三：离线安装（无网络时）
pip install --no-index --find-links=/path/to/packages -r requirements.txt
```

### 3.2 验证安装

```bash
# 验证所有依赖
python3 -c "import loguru, websockets, fastapi, uvicorn, pydantic; print('✅ 全部依赖已安装')"
```

## 四、常见故障排查

### 4.1 SSH登录失败

**现象**: 密码错误提示

**原因**: 输入法为中文

**解决**: 按Shift切换到英文输入法，密码为英文单引号 `'`

### 4.2 端口被占用

**现象**: `Address already in use`

**解决**:
```bash
# 查找占用进程
sudo lsof -i :8000

# 终止进程
pkill -f start_monitor.py

# 重新启动
python3 scripts/start_monitor.py
```

### 4.3 模块导入失败

**现象**: `ModuleNotFoundError: No module named 'xxx'`

**解决**:
```bash
# 确认已激活虚拟环境
source venv/bin/activate

# 重新安装依赖
pip install -r requirements.txt
```

### 4.4 网络连通性问题

**现象**: 无法访问云台相机或监测平台

**解决**:
```bash
# 测试网络连通性
ping 192.168.1.108
nc -zv 192.168.1.108 554

# 检查防火墙
sudo ufw status
sudo ufw allow 8000/tcp
sudo ufw allow 8765/tcp
```
