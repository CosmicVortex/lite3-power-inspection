## 二、故障排查

### 2.1 SSH登录失败

**现象**: 密码错误提示

**原因**: 输入法为中文

**解决**:
```bash
# 切换到英文输入法，密码为英文单引号
ssh ysc@192.168.1.103
# 密码: '
```

### 2.2 端口被占用

**现象**: `Address already in use`

**解决**:
```bash
# 查找占用进程
sudo lsof -i :8000
sudo lsof -i :8765

# 终止进程
pkill -f start_monitor.py
pkill -f demo_12min.py

# 重新启动
python3 scripts/start_monitor.py
```

### 2.3 依赖安装失败

**现象**: `ModuleNotFoundError: No module named 'xxx'`

**解决**:
```bash
# 确认已激活虚拟环境
source venv/bin/activate

# 使用国内镜像安装
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或离线安装
pip install --no-index --find-links=/path/to/packages -r requirements.txt
```

### 2.4 网络连通性问题

**现象**: 无法访问云台相机或监测平台

**解决**:
```bash
# 测试网络连通性
ping -c 2 192.168.1.108  # 云台相机
ping -c 2 192.168.1.200  # 监测平台

# 检查端口可达性
nc -zv 192.168.1.108 554  # RTSP
nc -zv 192.168.1.103 8765 # WebSocket

# 检查防火墙
sudo ufw status
sudo ufw allow 8000/tcp
sudo ufw allow 8765/tcp
```

### 2.5 UDP通信超时

**现象**: 运动控制指令无响应

**解决**:
```bash
# 检查UDP端口监听
netstat -uln | grep 43893

# 测试UDP通信
python3 -c "
import socket
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.sendto(b'\x01\x00\x04\x21\x00\x00\x00\x00\x00\x00\x00\x00', ('192.168.1.103', 43893))
sock.settimeout(1.0)
try:
    data, addr = sock.recvfrom(1024)
    print(f'UDP通信正常: {data.hex()}')
except socket.timeout:
    print('UDP通信超时，检查运动主机是否在线')
"
```

## 四、常见问题速查表

| 问题 | 解决方案 |
|------|----------|
| 密码错误 | 切换到英文输入法，密码为英文单引号 `'` |
| 端口占用 | `pkill -f start_monitor.py` 后重试 |
| 依赖缺失 | `pip install -r requirements.txt` |
| 模块导入失败 | 确认已激活虚拟环境 `source venv/bin/activate` |
| 网络不通 | 检查WiFi热点，确保设备在同一网段 |
| UDP超时 | 检查运动主机状态，确认心跳正常 |
