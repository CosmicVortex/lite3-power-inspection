## 一、概述

本指南介绍绝影Lite3电力巡检系统的环境诊断流程和故障排查方法。通过一键诊断脚本，可以快速识别环境问题并生成详细报告。

## 二、快速诊断

### 2.1 单命令诊断（推荐）

```bash
# 进入项目目录
cd /home/ysc/lite3-power-inspection

# 运行诊断（生成HTML/JSON/Markdown三份报告）
./scripts/run_diagnostic.sh
```

### 2.2 诊断内容

诊断脚本会自动检查以下内容：

| 类别 | 检查项 | 说明 |
|------|--------|------|
| 系统环境 | Python版本 | 需要 >= 3.8 |
| | 操作系统 | Linux/Ubuntu推荐 |
| | 内存空间 | 需要 >= 4GB可用 |
| | 磁盘空间 | 需要 >= 2GB可用 |
| Python依赖 | 核心包 | loguru, numpy, opencv等 |
| | GPU包 | torch, tensorrt（可选） |
| GPU环境 | CUDA | 检查CUDA版本 |
| | NVIDIA GPU | 检测GPU可用性 |
| | PyTorch CUDA | 检查GPU加速支持 |
| 网络连接 | 运动主机 | 192.168.1.103:43893 (UDP) |
| | 云台相机 | 192.168.1.108:80 (HTTP) |
| | RTSP流 | 192.168.1.108:554 |
| | 监测平台 | 192.168.1.200:8765 (WebSocket) |
| 配置文件 | inspection_config.yaml | 检查必要配置项 |
| 模型文件 | *.trt, *.onnx | 检测模型文件存在性 |

### 2.3 输出报告

诊断完成后会生成三份报告：

```
data/
├── diagnostic_report.html    # 可视化报告（浏览器打开）

```

## 三、常见问题排查

### 3.1 依赖安装问题

#### 问题：pip install 失败

**症状**：
```
Collecting loguru>=0.6.0
  Downloading loguru-0.7.2.tar.gz (58 kB)
ERROR: Could not install packages due to an OSError...
```

**解决方案**：
```bash
# 方案1：使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 方案2：升级pip
python -m pip install --upgrade pip

# 方案3：安装系统依赖
sudo apt-get install python3-dev python3-pip libffi-dev
```

#### 问题：缺少特定包

**症状**：
```
ModuleNotFoundError: No module named 'loguru'
```

**解决方案**：
```bash
# 单独安装缺失包
pip install loguru numpy opencv-python websockets requests pyyaml fastapi uvicorn pydantic

# 或安装所有核心依赖
pip install -r requirements.txt
```

### 3.2 GPU环境问题

#### 问题：CUDA不可用

**症状**：
```
⚠️  CUDA不可用（将使用模拟模式）
```

**说明**：这是正常现象，系统将自动降级到模拟模式。如需真实推理：

```bash
# 检查CUDA版本
nvcc --version

# 如果CUDA未安装，需要安装NVIDIA驱动和CUDA Toolkit
# Ubuntu 20.04 + CUDA 11.4
wget https://developer.download.nvidia.com/compute/cuda/11.4.0/local_installers/cuda_11.4.0_470.57.02_linux.run
sudo sh cuda_11.4.0_470.57.02_linux.run

# 验证安装
nvidia-smi
nvcc --version
```

#### 问题：TensorRT导入失败

**症状**：
```
ImportError: libtensorrt.so.x.x: cannot open shared object file
```

**解决方案**：
```bash
# 添加TensorRT到LD_LIBRARY_PATH
export LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu:$LD_LIBRARY_PATH

# 或将路径添加到/etc/ld.so.conf.d/tensorrt.conf
echo "/usr/lib/x86_64-linux-gnu" | sudo tee /etc/ld.so.conf.d/tensorrt.conf
sudo ldconfig
```

### 3.3 网络连接问题

#### 问题：目标设备不可达

**症状**：
```
⚠️  192.168.1.103:43893 (运动主机) - 超时
⚠️  192.168.1.108:80 (云台相机) - 不可达
```

**排查步骤**：

1. **检查网络配置**
   ```bash
   # 查看本机IP
   ip addr show
   
   # 确认在同一网段
   # 机器狗主机: 192.168.1.103
   # 云台相机: 192.168.1.108
   # 监测平台: 192.168.1.200
   ```

2. **测试连通性**
   ```bash
   # Ping测试
   ping -c 3 192.168.1.103
   ping -c 3 192.168.1.108
   
   # 检查端口
   nc -zv 192.168.1.103 43893
   nc -zv 192.168.1.108 80
   nc -zv 192.168.1.108 554
   ```

3. **检查防火墙**
   ```bash
   # 查看防火墙状态
   sudo ufw status
   
   # 添加规则
   sudo ufw allow 43893/udp
   sudo ufw allow 80/tcp
   sudo ufw allow 554/tcp
   sudo ufw allow 8765/tcp
   ```

4. **检查WiFi热点**
   ```bash
   # 如果是笔记本热点模式
   nmcli device wifi hotspot ifname wlan0 ssid "Lite3-Deploy" password "deploy123"
   
   # 确认热点IP
   ip addr show wlan0
   # 应该是 192.168.1.1
   ```

### 3.4 配置文件问题

#### 问题：配置解析失败

**症状**：
```
yaml.scanner.ScannerError: mapping values are not allowed here
```

**解决方案**：
```bash
# 检查配置文件语法
python -c "import yaml; yaml.safe_load(open('config/inspection_config.yaml'))"

# 使用正确的YAML格式
cat config/inspection_config.yaml
```

确保配置文件格式正确：
```yaml
network:
  robot_motion:
    ip: "192.168.1.103"    # 使用双引号
    port: 43893
```

### 3.5 端口占用问题

**症状**：
```
Address already in use
OSError: [Errno 98] Address already in use
```

**解决方案**：
```bash
# 查找占用端口的进程
sudo lsof -i :8000
sudo lsof -i :8765

# 杀死占用进程
sudo kill -9 <PID>

# 或使用不同端口启动
python3 scripts/start_monitor.py --port 8080 --ws-port 8765
```

## 四、机器狗本体诊断

当机器狗无法正常运行时，执行以下诊断：

### 4.1 运动主机诊断

```bash
# SSH登录运动主机
ssh ysc@192.168.1.103
# 密码: '（英文单引号）

# 检查进程
ps aux | grep joyai

# 检查UDP端口
netstat -uln | grep 43893

# 测试UDP通信
python3 -c "
import socket
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.sendto(b'\x01\x00\x04\x21\x00\x00\x00\x00\x00\x00\x00\x00', ('192.168.1.103', 43893))
sock.settimeout(1.0)
try:
    data, addr = sock.recvfrom(1024)
    print(f'收到响应: {data.hex()}')
except socket.timeout:
    print('超时，运动主机可能未运行')
"

# 重启运动主机服务
sudo systemctl restart joyai-motion
```

### 4.2 云台相机诊断

```bash
# 测试HTTP连接
curl -u admin:123456 http://192.168.1.108/merlin/Login.cgi?Type=WEB

# 测试云台控制
curl -u admin:123456 "http://192.168.1.108/merlin/SetPtzangle.cgi" \
     -H "Content-Type: application/json" \
     -d '{"Angle": {"yaw": 45, "pitch": -30}}'

# 测试RTSP流
ffplay rtsp://admin:123456@192.168.1.108:554/id=1&type=0

# 检查云台日志
ssh admin@192.168.1.108 "tail -n 50 /var/log/syslog"
```

### 4.3 感知主机诊断

```bash
# SSH登录感知主机
ssh ysc@192.168.1.103

# 检查GPU状态
nvidia-smi

# 检查CUDA版本
nvcc --version

# 检查TensorRT
python3 -c "import tensorrt; print(tensorrt.__version__)"

# 检查Python环境
source venv/bin/activate
python3 -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

# 检查项目依赖
pip list | grep -E "loguru|numpy|opencv|websockets|fastapi"

# 运行单元测试
python3 -m pytest tests/ -v
```

### 4.4 联合诊断脚本

创建 `/home/ysc/lite3-power-inspection/scripts/joint_diagnostic.sh`：

```bash
#!/bin/bash
# 绝影Lite3 联合诊断脚本
# 用法: ./scripts/joint_diagnostic.sh

set -e

echo "=========================================="
echo "绝影Lite3 联合诊断"
echo "=========================================="
echo ""

# 1. 运动主机诊断
echo "[1/4] 运动主机诊断..."
ssh ysc@192.168.1.103 "ps aux | grep -E 'joyai|python' | grep -v grep" || echo "  ⚠️  无法连接到运动主机"
echo ""

# 2. 云台相机诊断
echo "[2/4] 云台相机诊断..."
curl -s -u admin:123456 http://192.168.1.108/merlin/GetFlyStateInfo.cgi 2>/dev/null && echo "  ✓ 云台响应正常" || echo "  ⚠️  云台无响应"
echo ""

# 3. 感知主机诊断
echo "[3/4] 感知主机诊断..."
ssh ysc@192.168.1.103 "nvidia-smi --query-gpu=name,memory.used,utilization.gpu --format=csv,noheader" 2>/dev/null || echo "  ⚠️  无法获取GPU信息"
echo ""

# 4. 监测平台诊断
echo "[4/4] 监测平台诊断..."
curl -s http://192.168.1.1:8000/api/status 2>/dev/null && echo "  ✓ 监测平台响应正常" || echo "  ℹ️  监测平台未运行"
echo ""

echo "=========================================="
echo "诊断完成"
echo "=========================================="
```
