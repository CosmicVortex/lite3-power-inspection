## 二、核心接口

### 2.1 登录认证

```http
GET /merlin/Login.cgi?Type=WEB&Expires=30 HTTP/1.1
Host: 192.168.1.108
Authorization: Basic YWRtaW46MTIzNDU2  # admin:123456

# 响应
HTTP/1.1 200 OK
Set-Cookie: MerlinSession=xxxxxx; Path=/merlin
```

### 2.2 心跳保持

```http
GET /merlin/Heartbeat.cgi HTTP/1.1
Host: 192.168.1.108
Cookie: MerlinSession=xxxxxx

# 说明: 每10秒调用一次，Session超过30秒无心跳将失效
```

### 2.3 角度控制

```http
POST /merlin/SetPtzangle.cgi HTTP/1.1
Host: 192.168.1.108
Content-Type: application/json
Cookie: MerlinSession=xxxxxx

{
    "Angle": {
        "yaw": 45,
        "pitch": -30,
        "roll": 0
    }
}

# 角度范围:
#   yaw:   -280° ~ 280°
#   pitch: -115° ~  40°
```

### 2.4 变倍控制

```http
GET /merlin/ZoomCtrl.cgi?zoom=10 HTTP/1.1
Host: 192.168.1.108
Cookie: MerlinSession=xxxxxx

# zoom范围: 1 (广角) ~ 10 (光学变焦) + 16× 数字变焦
```

### 2.5 状态查询

```http
GET /merlin/GetFlyStateInfo.cgi HTTP/1.1
Host: 192.168.1.108
Cookie: MerlinSession=xxxxxx

# 响应示例
{
    "Zoom": {"zoom": 10},
    "Angle": {"yaw": 45.0, "pitch": -30.0},
    "Status": "OK"
}
```

## 四、Python封装示例

```python
import requests
from threading import Thread
import time

class MerlinSession:
    """数尔WEB2.0云台控制会话"""
    
    def __init__(self, base_url="http://192.168.1.108", 
                 username="admin", password="123456",
                 heartbeat_interval=10.0):
        self.base_url = base_url.rstrip('/')
        self.session = requests.Session()
        self.session.auth = (username, password)
        self.heartbeat_interval = heartbeat_interval
        self._heartbeat_thread = None
        
    def login(self):
        """登录获取Session"""
        resp = self.session.get(f"{self.base_url}/merlin/Login.cgi", 
                                params={"Type": "WEB", "Expires": "30"})
        return resp.status_code == 200
    
    def start_heartbeat(self):
        """启动心跳线程"""
        self._heartbeat_thread = Thread(target=self._heartbeat_loop, daemon=True)
        self._heartbeat_thread.start()
        
    def _heartbeat_loop(self):
        """心跳循环"""
        while True:
            time.sleep(self.heartbeat_interval)
            self.session.get(f"{self.base_url}/merlin/Heartbeat.cgi")
            
    def set_ptz_angle(self, yaw, pitch, roll=0):
        """设置云台角度"""
        resp = self.session.post(
            f"{self.base_url}/merlin/SetPtzangle.cgi",
            json={"Angle": {"yaw": yaw, "pitch": pitch, "roll": roll}}
        )
        return resp.json()
    
    def zoom_ctrl(self, zoom_level):
        """变倍控制 (1-10)"""
        resp = self.session.get(
            f"{self.base_url}/merlin/ZoomCtrl.cgi",
            params={"zoom": zoom_level}
        )
        return resp.status_code == 200
    
    def get_state(self):
        """获取云台状态"""
        resp = self.session.get(
            f"{self.base_url}/merlin/GetFlyStateInfo.cgi"
        )
        return resp.json()
    
    def close(self):
        """关闭会话"""
        if self._heartbeat_thread:
            self._heartbeat_thread.stop()
        self.session.close()


# 使用示例
if __name__ == "__main__":
    ptz = MerlinSession()
    ptz.login()
    ptz.start_heartbeat()
    
    # 广角巡检
    ptz.set_ptz_angle(yaw=0, pitch=-30)
    
    # 触发变焦
    ptz.zoom_ctrl(10)
    
    # 获取状态
    state = ptz.get_state()
    print(f"当前变倍: {state['Zoom']['zoom']}")
    
    ptz.close()
```

## 六、注意事项

1. **Session管理**: 登录成功后必须定期发送心跳，否则Session会在30秒后过期
2. **角度限制**: 俯仰角pitch范围为-115°~40°，超出范围指令将失效
3. **变焦稳定**: 变焦后需等待500ms让云台稳定再拍照
4. **权限管理**: 默认账号密码为admin/123456，生产环境建议修改
5. **并发限制**: 同一云台实例最多支持3个并发连接
