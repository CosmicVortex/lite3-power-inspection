## 一、部署主机确认

### 1.1 系统架构

绝影Lite3电力巡检系统部署在**双主机架构**上：

| 主机类型 | IP地址 | 硬件型号 | 功能定位 |
|----------|--------|----------|----------|
| **感知主机** | 192.168.1.103 | NVIDIA Jetson Xavier NX | AI推理、视觉处理、系统控制 |
| **运动主机** | 192.168.1.103 | Rockchip RK3588 | 运动控制、步态规划、实时通信 |

> **重要说明**：两个主机共享同一个IP地址（192.168.1.103），通过内部网络区分服务。

### 1.2 官方文档依据

根据 `docs/00-参考资料/00-绝影Lite3开发指南索引.md` 和 `docs/00-参考资料/01-绝影Lite3产品手册V2.0.0.md`：

```
| 模块 | 配置 |
|------|------|
| 运动主机 | Rockchip RK3588，8核CPU |
| 感知主机 | NVIDIA Jetson Xavier NX |
| 操作系统 | Ubuntu 20.04 / ROS2 |
```

| 参数 | 规格值 | 单位 |
|------|--------|------|
| **GPU架构** | Volta | - |

| **GPU算力（INT8）** | 42 | TOPS |
| **GPU频率** | 921 | MHz |

| **CPU** | 6核 ARM Cortex-A78AE | - |
| **CPU频率** | 最高 1.9 | GHz |
| **总内存** | 8 | GB（与GPU共享） |
| **存储接口** | M.2 Key M | - |
| **电源** | 15W（典型） | W |
| **操作系统** | Ubuntu 20.04 LTS | - |

#### 联网检索确认

根据NVIDIA官方文档和公开资料：
- ✅ **GPU存在**：NVIDIA Jetson Xavier NX 配备独立GPU
- ✅ **CUDA支持**：完整支持CUDA 11.x
- ✅ **TensorRT支持**：支持TensorRT 8.x
- ✅ **PyTorch支持**：支持torch 1.x + CUDA

### 2.2 运动主机（RK3588）

#### 官方规格（据Rockchip官网）

| 参数 | 规格值 | 单位 |
|------|--------|------|
| **CPU架构** | ARM Cortex-A76/A55 | - |
| **CPU核心数** | 8核（4×A76 + 4×A55） | 个 |
| **CPU最高频率** | 2.4 | GHz |
| **GPU** | ARM Mali-G610 MP4 | - |
| **GPU算力** | ~0.5 | TFLOPS |
| **NPU算力** | 6 | TOPS |
| **总内存** | 8 | GB（LPDDR4/LPDDR5） |
| **存储接口** | eMMC / NVMe SSD | - |
| **操作系统** | Ubuntu 20.04 / Android | - |

#### 关键说明

⚠️ **RK3588的GPU性能有限**：
- GPU仅为嵌入式Mali-G610，算力约0.5 TFLOPS
- **不适合运行深度学习推理**
- NPU（6 TOPS）可用于轻量级AI推理
- 主要职责：运动控制、步态规划、实时通信

## 三、GPU环境评估

### 3.1 GPU存在性确认

| 主机 | GPU型号 | 算力 | 部署用途 |
|------|---------|------|----------|
| 感知主机 | Jetson Xavier NX | 21 TOPS (FP16) | ✅ 主部署目标 |
| 运动主机 | RK3588 Mali-G610 | 0.5 TFLOPS | ❌ 不用于AI推理 |

### 3.2 感知主机GPU环境检查清单

```bash
# 在机器狗感知主机上执行以下命令检查GPU环境

# 1. 检查nvidia-smi是否存在
nvidia-smi

# 预期输出（示例）：
# +-----------------------------------------------------------------------------+
# | NVIDIA-SMI 470.57.02    Driver Version: 470.57.02    CUDA Version: 11.4   |
# |-------------------------------+----------------------+----------------------+
# | GPU  Name        Persistence-M| Bus-Id        Disp.A | Volatile Uncorr. ECC |
# | Fan  Temp  Perf  Pwr:Usage/Cap|         Memory-Usage | GPU-Util  Compute M. |
# |===============================+======================+======================|
# |   0  Xavier NX          Off  | 00000000:0000      Off |                    0 |
# | N/A   45C    P0    7W / 15W |     0MiB /  8176MiB |      0%      A. Mode |
# +-------------------------------+----------------------+----------------------+

# 2. 检查CUDA版本
nvcc --version

# 预期输出：
# Cuda compilation tools, release 11.4, V11.4.120

# 3. 检查TensorRT是否安装
python3 -c "import tensorrt; print(tensorrt.__version__)"

# 预期输出：8.x.x

# 4. 检查PyTorch CUDA支持
python3 -c "import torch; print(f'CUDA可用: {torch.cuda.is_available()}')"

# 预期输出：CUDA可用: True
```

### 3.3 部署条件判断

#### ✅ 满足部署条件（如果）

| 检查项 | 状态 | 说明 |
|--------|------|------|
| GPU存在 | ✅ | Jetson Xavier NX配备GPU |
| CUDA驱动 | ✅ | 需要 >= 470.57.02 |
| CUDA Toolkit | ✅ | 需要 >= 11.4 |
| TensorRT | ⚠️ | 建议安装 >= 8.0 |
| PyTorch | ⚠️ | 建议安装 >= 1.13 |

#### ❌ 不满足部署条件（如果出现）

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| nvidia-smi不存在 | 驱动未安装或不是Jetson | 重新烧录JetPack系统镜像 |
| CUDA版本过低 | JetPack版本太旧 | 升级JetPack到5.x |
| TensorRT未安装 | 未安装完整开发环境 | `pip install tensorrt` |
| PyTorch无CUDA支持 | 安装了CPU版本 | 重新安装GPU版本 |

## 四、模拟模式 vs 真实模式

### 4.1 模拟模式（无需GPU）

**适用场景**：
- 演示验证
- 功能测试
- 算法开发

**运行要求**：
- Python 3.8+
- 9个核心依赖包
- 无需GPU

**运行命令**：
```bash
python3 scripts/demo_12min.py --mode simulation
```

### 4.2 真实模式（需要GPU）

**适用场景**：
- 竞赛演示（使用真实模型）
- 生产环境部署

**运行要求**：
- GPU环境（Jetson Xavier NX）
- CUDA 11.4+
- PyTorch + CUDA支持
- TensorRT 8.0+
- 训练好的模型文件

**运行命令**：
```bash
python3 scripts/demo_12min.py --mode real
```

### 4.3 混合模式（可选）

**适用场景**：
- 部分模块使用真实模型
- 部分模块使用模拟数据

**运行命令**：
```bash
python3 scripts/demo_12min.py --mode hybrid
```

## 五、部署建议

### 5.1 推荐部署路径

根据官方文档和硬件规格分析：

```
推荐部署主机：感知主机（Jetson Xavier NX）
IP地址：192.168.1.103
原因：
1. 配备NVIDIA GPU，支持AI推理
2. 官方感知开发手册针对此主机设计
3. 预装Ubuntu 20.04 + ROS2环境
4. 提供完整的开发工具链
```

### 5.2 部署前检查清单

```bash
# 在机器狗感知主机上执行

# 1. 确认GPU环境
nvidia-smi
nvcc --version

# 2. 检查Python版本
python3 --version
# 应输出：Python 3.8.x 或更高

# 3. 检查磁盘空间
df -h
# 应至少有2GB可用空间

# 4. 检查内存
free -h
# 应至少有4GB可用内存

# 5. 检查网络连接
ping -c 2 192.168.1.108  # 云台相机
ping -c 2 192.168.1.200  # 监测平台
```

### 5.3 根据检查结果调整部署策略

#### 情况A：GPU环境完整

```
状态：nvidia-smi正常 + CUDA可用 + TensorRT已安装
策略：可直接部署真实模式
命令：python3 scripts/demo_12min.py --mode real
```

#### 情况B：GPU存在但缺少依赖

```
状态：nvidia-smi正常，但PyTorch/TensorRT未安装
策略：先安装GPU依赖，再部署
命令：
  pip install -r requirements-gpu.txt
  python3 scripts/demo_12min.py --mode real
```

#### 情况C：无GPU环境

```
状态：nvidia-smi不存在 或 GPU不可用
策略：使用模拟模式
命令：
  pip install -r requirements.txt
  python3 scripts/demo_12min.py --mode simulation
```
