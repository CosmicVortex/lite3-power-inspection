## 一、部署架构说明

本系统采用**双部署架构**：

| 部署位置 | 内容 | IP地址 | 端口 |
|---------|------|--------|------|
| **感知主机** (Jetson NX) | 巡检程序、AI推理、数据采集 | 192.168.1.103 | 43893/8080 |
| **监测平台** (独立笔记本) | Web界面、数据可视化、运动控制 | localhost | 8000/8765 |

> **重要说明**：监测平台不再部署于感知主机，而是独立运行在操作员笔记本上，通过WebSocket自动连接感知主机。

## 二、感知主机部署

### 2.1 一键部署命令

```bash
# SSH登录感知主机
ssh ysc@192.168.1.103
# 密码: '（英文单引号）

# 解压部署包并一键部署
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
./scripts/deploy.sh simulation
```

### 2.2 部署包信息

```
文件名: lite3-power-inspection.zip
大小: 约 15.6 MB
内容: 129个文件
     - src/: 源代码（巡检程序）
     - models/: AI模型文件
     - docs/: 技术文档
     - scripts/: 部署脚本
```

### 2.3 验证安装


## 三、监测平台部署（独立笔记本）

### 3.1 便携包获取

```bash
# 从GitHub下载或从项目deliverables目录复制
# 文件名: monitor-platform-portable.zip (11KB)
```

### 3.2 Windows部署

```cmd
:: 1. 解压到目录（如 D:\monitor-platform）
:: 2. 双击运行启动脚本
start_monitor.bat

:: 3. 访问监测平台
:: http://localhost:8000
```

### 3.3 Linux/macOS部署

```bash
# 1. 解压
unzip monitor-platform-portable.zip
cd monitor-platform

# 2. 启动（自动创建venv并安装依赖）
chmod +x start_monitor.sh
./start_monitor.sh

# 3. 访问监测平台
echo "http://localhost:8000"
```

### 3.4 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| Web界面 | http://localhost:8000 | 主监控面板 |
| API文档 | http://localhost:8000/docs | Swagger UI |
| WebSocket | ws://localhost:8765/ws | 数据通信 |

## 四、双系统联调

### 4.1 网络要求

```
感知主机: 192.168.1.103 (WiFi连接)
监测平台: 同一WiFi网络下的笔记本
```

### 4.2 连接验证

```bash
# 在笔记本上测试连接
ping 192.168.1.103
nc -zv 192.168.1.103 8765
```

### 4.3 启动顺序

```
1. 先启动监测平台（笔记本）
   → 打开 http://localhost:8000
   
2. 再启动感知主机巡检程序
   → 自动连接监测平台
   
3. 等待WebSocket连接成功
   → 界面显示"已连接"
```

## 六、故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| WebSocket连接失败 | 网络不通 | 检查IP配置和防火墙 |
| 监测平台无数据 | 感知主机未启动 | 检查inspector.py是否运行 |
| 运动控制无响应 | UDP被拦截 | 检查运动主机状态 |
| 视频流无法显示 | RTSP服务异常 | 检查云台相机连接 |

## 七、完整部署流程总结

```bash
# ========== 赛前准备 ==========
# 1. 生成离线包（有网络时）
python3 scripts/package_offline.py --output offline-deploy

# 2. 传输部署包
scp lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/
scp monitor-platform-portable.zip user@laptop:/tmp/

# ========== 比赛当天 ==========
# 3. 感知主机部署（SSH登录）
ssh ysc@192.168.1.103
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
./scripts/deploy.sh simulation

# 4. 监测平台部署（笔记本）
cd /tmp && unzip -q monitor-platform-portable.zip
cd monitor-platform
./start_monitor.sh   # Linux
# 或 start_monitor.bat  # Windows

# 5. 验证连接
# 浏览器打开 http://localhost:8000
# 确认显示"已连接"和实时数据
```
