## 二、部署流程

### 2.1 一键部署命令（唯一执行路径）

```bash
# 1. SSH登录感知主机
ssh ysc@192.168.1.103
# 密码: '（英文单引号）

# 2. 解压部署包并一键部署
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
./scripts/deploy.sh simulation
```

### 2.2 详细部署步骤

#### 步骤一：传输部署包

**使用MobaXterm文件面板**：
1. 打开MobaXterm并连接到 `ysc@192.168.1.103`（密码：`'`）
2. 在左侧远程文件面板导航到 `/home/ysc/`
3. 将 `lite3-power-inspection.zip` 从本地拖拽到远程目录

**或使用SCP命令**：
```bash
scp lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/
```

#### 步骤二：SSH登录并解压

```bash
ssh ysc@192.168.1.103
# 密码: '

cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
```

#### 步骤三：创建虚拟环境并安装依赖

```bash
# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装核心依赖
pip install -q -r requirements.txt
```

**离线安装**（无网络时）：
```bash
# 从USB设备安装
pip install --no-index --find-links=/mnt/usb/offline-deploy/packages -r requirements.txt
```

#### 步骤四：验证安装

```bash
# 验证核心依赖
python3 -c "import loguru, websockets, fastapi, uvicorn, pydantic; print('✅ 全部依赖已安装')"

# 验证GPU环境（可选）
python3 -c "import torch; print(f'PyTorch版本: {torch.__version__}'); print(f'CUDA可用: {torch.cuda.is_available()}')"
```

## 五、离线部署准备

```bash
cd ~/lite3-power-inspection
python3 scripts/package_offline.py --output offline-deploy
```

```
│   ├── fastapi-xxx.whl
│   ├── uvicorn-xxx.whl
│   └── pydantic-xxx.whl

```

### 5.2 离线部署流程（无网络时）


## 六、故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| SSH密码错误 | 输入法为中文 | 按Shift切换英文输入法 |
| 端口被占用 | 旧进程残留 | `pkill -f start_monitor.py` |
| 依赖安装失败 | 无网络或镜像问题 | 使用离线包或国内镜像 |
| 模块导入失败 | 未激活虚拟环境 | `source venv/bin/activate` |
| WebSocket连接失败 | 服务端未启动 | 检查start_monitor.py是否运行 |
| UDP通信超时 | 运动主机未响应 | 检查运动主机状态和心跳 |
