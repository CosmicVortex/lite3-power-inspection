## 三、模拟运行架构

### 3.1 三级降级策略

| 级别 | 模式 | 触发条件 | 适用场景 |
|------|------|----------|----------|
| L1 | 模拟模式 | 模型文件不存在 | 开发测试、演示准备 |
| L2 | 混合模式 | 手动指定 `--mode hybrid` | 硬件联调 |
| L3 | 真实模式 | 模型文件存在且手动指定 `--mode real` | 正式演示 |

### 3.2 模拟模块映射

| 原始模块 | 模拟实现 | 数据规范 |
|----------|----------|----------|
| `YOLODetector` | 随机生成检测结果 | 置信度 0.7~0.95，宽度 0.1~0.5mm |
| `TensorRTModel` | 返回随机推理张量 | 形状 (1, 80, 8400)，值域 0.5~0.9 |
| `SnapshotServer` | 生成测试图片 | 640×480 PNG/JPEG |
| `SimulationGenerator` | 按预设脚本生成数据 | 符合 API 文档 payload 结构 |
| `TemperatureMonitor` | 模拟温度变化曲线 | 38→52℃，升温速率 2~4℃/min |

### 3.3 模式切换命令

```bash
# 模拟模式（默认，无需模型文件）
python3 scripts/run_demo.py --mode simulation

# 混合模式（运动真实，感知模拟）
python3 scripts/run_demo.py --mode hybrid

# 真实模式（需模型文件 yolov8s-crack.trt 和 unet-crack.onnx）
python3 scripts/run_demo.py --mode real
```
