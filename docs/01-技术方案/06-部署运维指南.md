## 二、一键部署命令（唯一执行路径）

### 场景A：赛前准备（有网络）

```bash
# 1. 传输部署包到机器狗主机（MobaXterm文件面板拖拽或SCP）
scp lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/

# 2. SSH登录并一键部署
ssh ysc@192.168.1.103
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
python3 -m venv venv && source venv/bin/activate
pip install -q -r requirements.txt
```

### 场景B：竞赛现场（无网络）

```bash
# 1. 从USB解压项目
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q /mnt/usb/lite3-power-inspection.zip

# 2. 创建虚拟环境并安装依赖（使用离线包）
python3 -m venv venv && source venv/bin/activate
pip install --no-index --find-links=/mnt/usb/offline-deploy/packages -r requirements.txt
```

### 统一部署命令（推荐）

```bash
# 一键部署脚本
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
./scripts/deploy.sh simulation
```

## 三、启动与测试

### 3.1 启动监测平台（后台运行）

```bash
source venv/bin/activate
nohup python3 scripts/start_monitor.py > data/logs/monitor.log 2>&1 &
```

**访问地址**: http://192.168.1.103:8000


## 六、故障排查

| 问题 | 解决方案 |
|------|----------|
| SSH密码错误 | 切换到英文输入法，密码为英文单引号 `'` |
| 端口占用 | `pkill -f start_monitor.py` 后重试 |
| 依赖安装失败 | `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 模块导入失败 | 确认已激活虚拟环境：`source venv/bin/activate` |

## 七、完整部署流程总结

```bash
# ========== 赛前准备（有网络）==========
# 1. 笔记本电脑上生成离线包
python3 scripts/package_offline.py --output offline-deploy

# 2. 传输到机器狗主机（MobaXterm文件面板拖拽）
scp lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/
scp -r offline-deploy/ ysc@192.168.1.103:/home/ysc/

# ========== 比赛当天（无网络）==========
# 3. SSH登录
ssh ysc@192.168.1.103
# 密码: '

# 4. 一键部署
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q /home/ysc/lite3-power-inspection.zip
python3 -m venv venv && source venv/bin/activate
pip install --no-index --find-links=/home/ysc/offline-deploy/packages -r requirements.txt

# 5. 启动监测平台
nohup python3 scripts/start_monitor.py > data/logs/monitor.log 2>&1 &

# 6. 运行演示
python3 scripts/demo_12min.py --mode simulation
```
