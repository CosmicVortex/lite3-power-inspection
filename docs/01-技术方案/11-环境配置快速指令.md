# 绝影Lite3 机器狗环境配置确认 - 完整流程

## 步骤一：传输采集脚本到机器狗

在笔记本电脑上执行：
```bash
scp scripts/gather_info.sh ysc@192.168.1.103:/home/ysc/lite3-power-inspection/scripts/
scp scripts/gather_system_info.py ysc@192.168.1.103:/home/ysc/lite3-power-inspection/scripts/
```

密码：`'`（英文单引号）

## 步骤二：SSH登录机器狗

```bash
ssh ysc@192.168.1.103
```

密码：`'`（英文单引号）

## 步骤三：运行环境信息采集

```bash
cd /home/ysc/lite3-power-inspection
./scripts/gather_info.sh
```

或运行Python版本获取更详细信息：
```bash
python3 scripts/gather_system_info.py --output data/system_info_report.md
```

## 步骤四：查看采集报告

```bash
cat data/system_info_report.md
```

## 步骤五：根据反馈调整环境

参考文档：docs/01-技术方案/10-环境配置确认指南.md

常见问题处理：
- Python版本过低：安装Python 3.8+
- 缺少依赖：pip install -r requirements.txt
- 需要GPU支持：pip install -r requirements-gpu.txt
- 网络不通：检查WiFi热点和防火墙

## 步骤六：验证配置

```bash
./scripts/check_deployment.sh
./scripts/run_diagnostic.sh
```

## 步骤七：反馈结果

将以下信息反馈给技术支持：
```bash
echo "主机: $(hostname)"
echo "OS: $(uname -s) $(uname -r)"
echo "Python: $(python3 --version)"
echo "GPU: $(nvidia-smi --query-gpu=name --format=csv,noheader 2>/dev/null || echo '无')"
echo "CUDA: $(nvcc --version 2>/dev/null | grep release | awk '{print $NF}' || echo '无')"
cat data/system_info_report.md
```
