## 一、数据分类

### 1.1 数据类型划分

| 类型 | 说明 | 存储位置 | 保留期限 |
|------|------|----------|----------|
| 巡检数据 | 裂缝检测结果、温度测量值 | SQLite缓存 | 永久 |
| 图像数据 | 检测截图、热成像图 | data/images/ | 30天 |
| 日志数据 | 系统运行日志 | data/logs/ | 7天 |
| 配置数据 | 系统配置文件 | config/ | 永久 |
| 临时数据 | 缓冲区、缓存文件 | data/cache/ | 重启清理 |

## 三、图像数据规范

### 3.1 图像命名规则

| 类型 | 命名格式 | 示例 |
|------|----------|------|
| 检测截图 | CRACK-WP{航点}-{时间戳}.jpg | CRACK-WP001-1735668123.jpg |
| 热成像图 | TEMP-WP{航点}-{时间戳}.jpg | TEMP-WP004-1735668200.jpg |
| 全景图 | PAN-WP{航点}-{时间戳}.jpg | PAN-WP001-1735668000.jpg |

### 3.2 图像存储路径

```
data/
├── images/
│   ├── crack/          # 裂缝检测截图
│   ├── thermal/        # 热成像图
│   └── panorama/       # 全景图
├── logs/
│   └── app_YYYY-MM-DD.log
└── cache/
    └── inspection.db   # SQLite缓存
```

## 四、日志数据规范

### 4.1 日志级别定义

| 级别 | 代码 | 用途 | 示例 |
|------|------|------|------|
| DEBUG | D | 调试信息 | 变量值、中间结果 |
| INFO | I | 正常信息 | 操作成功、状态变化 |
| WARNING | W | 警告信息 | 资源不足、性能下降 |
| ERROR | E | 错误信息 | 模块失败、通信异常 |
| CRITICAL | C | 严重错误 | 系统崩溃、数据丢失 |

### 4.2 日志格式

```
[2025-09-16 10:30:00] [INFO] [Inspector] 完成航点WP001巡检，检测到裂缝宽0.12mm
[2025-09-16 10:30:05] [WARNING] [PTZController] 云台yaw角度超出范围: 285°
[2025-09-16 10:30:10] [ERROR] [WebSocketGateway] 连接超时，尝试重连...
```

## 五、数据备份与恢复

### 5.1 备份策略

| 数据类型 | 备份频率 | 备份方式 |
|----------|----------|----------|
| 巡检数据 | 每日 | SQLite导出为SQL文件 |
| 图像数据 | 每周 | 打包压缩到外部存储 |
| 日志数据 | 每日 | 归档旧日志文件 |
| 配置数据 | 修改时 | git版本控制 |

### 5.2 备份命令

```bash
# 备份巡检数据
sqlite3 data/cache/inspection.db ".backup '/mnt/usb/backup/inspection_$(date +%Y%m%d).db'"

# 备份图像数据
tar -czf /mnt/usb/backup/images_$(date +%Y%m%d).tar.gz data/images/

# 备份配置文件
cp -r config/ /mnt/usb/backup/config_backup_$(date +%Y%m%d)/
```

## 六、数据质量管理

### 6.1 数据完整性检查

```bash
# 检查SQLite数据库完整性
sqlite3 data/cache/inspection.db "PRAGMA integrity_check;"

# 检查图像文件完整性
find data/images/ -type f -name "*.jpg" -exec file {} \; | grep -v "JPEG"
```

### 6.2 数据清理脚本

```bash
#!/bin/bash
# 清理7天前的日志
find data/logs/ -name "*.log" -mtime +7 -delete

# 清理30天前的图像
find data/images/ -name "*.jpg" -mtime +30 -delete

# 清理缓存文件
rm -rf data/cache/*.tmp
```

## 七、数据导入导出

### 7.1 导出巡检报告

```bash
python3 scripts/export_inspection.py --output report.csv
```

生成的CSV格式：
```csv
inspection_id,waypoint_id,timestamp,defect_type,subtype,width_mm,length_mm,confidence

```

### 7.2 导入配置数据

```bash
python3 scripts/import_config.py --file backup/config.yaml
```
