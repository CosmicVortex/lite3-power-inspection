# 绝影Lite3 离线部署指南

> **版本**: V1.6  
> **编制日期**: 2026-08-20  
> **适用场景**: 无网络环境的机器狗主机部署

---

## 一、概述

本指南介绍如何在**无网络环境**下完成绝影Lite3电力巡检系统的部署。通过预先准备的离线部署包，无需联网即可安装所有依赖并启动系统。

---

## 二、部署前准备

### 2.1 系统要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | ARM Cortex-A53 4核 | NVIDIA Jetson Xavier NX |
| 内存 | 4GB | 8GB |
| 存储 | 2GB可用空间 | 16GB以上 |
| 操作系统 | Ubuntu 20.04/22.04 | Ubuntu 22.04 LTS |
| Python | 3.8+ | 3.10+ |

### 2.2 准备离线部署包

在有网络的环境中执行以下命令：

```bash
# 进入项目目录
cd /path/to/lite3-power-inspection

# 准备离线包（会下载所有依赖）
python3 scripts/package_offline.py --output offline-deploy

# 或者跳过下载（如果依赖已准备）
python3 scripts/package_offline.py --output offline-deploy --skip-download
```

生成的目录结构：

```
offline-deploy/
├── packages/              # Python依赖wheel包
│   ├── loguru-xxx.whl
│   ├── numpy-xxx.whl
│   ├── opencv_python-xxx.whl
│   └── ...
├── project/               # 项目源代码
│   ├── src/
│   ├── scripts/
│   ├── docs/
│   ├── monitor_platform/
│   ├── config/
│   ├── requirements.txt
│   └── README.md
└── README.md              # 使用说明
```

### 2.3 传输到目标机器

```bash
# 方法1: 使用USB设备
cp -r offline-deploy /mnt/usb/

# 方法2: 使用SCP（需临时网络）
scp -r offline-deploy/ ysc@192.168.1.103:/home/ysc/

# 方法3: 使用Git LFS
git add offline-deploy/
git commit -m "添加离线部署包"
git push
```

## 三、执行离线部署

### 3.1 SSH登录机器狗主机

```bash
ssh ysc@192.168.1.103
```

### 3.2 解压并进入项目目录

```bash
# 如果从USB传输
cp -r /mnt/usb/offline-deploy ~/
cd ~/lite3-power-inspection

# 如果从SCP传输
cd ~/lite3-power-inspection
```

### 3.3 执行一键部署

```bash
# 指定离线包路径进行部署
./scripts/deploy_oneclick.sh --offline-dir ../offline-deploy/packages

# 或使用Python版本
python3 scripts/deploy_oneclick.py --offline-dir ../offline-deploy/packages
```

### 3.4 部署过程说明

脚本会自动执行以下步骤：

1. **环境检测** - 检查Python版本、系统依赖、GPU环境
2. **目录创建** - 创建 data/, logs/, models/ 等必要目录
3. **虚拟环境** - 创建Python虚拟环境（venv）
4. **依赖安装** - 从离线包安装Python依赖（无需网络）
5. **服务启动** - 启动监测平台服务
6. **验证检查** - 验证所有组件正常运行

### 3.5 部署成功标志

```

==========================================

查看日志: tail -f data/logs/monitor.log
```

## 四、故障排查

### 4.1 常见问题及解决方案

#### 问题1: 缺少Python版本

**症状**:
```
❌ Python版本过低: 3.6.9 (需要 >= 3.8)
```

**解决方案**:
```bash
# Ubuntu 20.04
sudo apt-get update
sudo apt-get install python3.8 python3.8-venv python3.8-dev

# 设置默认Python版本
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.8 2
```

#### 问题2: 离线包不完整

**症状**:
```
❌ 安装失败: 缺少 wheel包: loguru
```

**解决方案**:
```bash
# 重新生成离线包
cd /path/to/lite3-power-inspection
python3 scripts/package_offline.py --output offline-deploy

# 检查wheel包是否完整
ls -lh offline-deploy/packages/*.whl
```

#### 问题3: 端口被占用

**症状**:
```
❌ 启动失败: [Errno 98] Address already in use
```

**解决方案**:
```bash
# 查找占用端口的进程
sudo lsof -i :8000

# 终止进程
sudo kill -9 <PID>

# 或修改配置使用其他端口
vim config/inspection_config.yaml
# 修改 port: 8000 为其他端口
```

#### 问题4: 权限不足

**症状**:
```
❌ PermissionError: [Errno 13] Permission denied
```

**解决方案**:
```bash
# 确保脚本有执行权限
chmod +x scripts/deploy_oneclick.sh
chmod +x scripts/*.py

# 使用正确的用户执行
sudo -u ysc ./scripts/deploy_oneclick.sh --offline-dir ../offline-deploy/packages
```

### 4.2 查看详细日志

```bash
# 监测系统日志
tail -f data/logs/monitor.log

# 查看部署日志
cat data/logs/deploy_$(date +%Y%m%d).log

# 运行诊断工具
./scripts/run_diagnostic.sh --full
```

### 4.3 手动安装依赖

如果自动安装失败，可手动安装：

```bash
# 激活虚拟环境
source venv/bin/activate

# 从离线包目录安装
pip install --no-index --find-links=/path/to/packages -r requirements.txt

# 或逐个安装
pip install --no-index --find-links=/path/to/packages loguru numpy opencv-python websockets requests pyyaml fastapi uvicorn pydantic
```

## 五、启动服务

### 5.1 启动监测平台

```bash
# 方式1: 使用一键脚本
./scripts/deploy_oneclick.sh --start

# 方式2: 手动启动
source venv/bin/activate
python3 scripts/start_monitor.py
```

### 5.2 启动演示程序

```bash
# 模拟模式（无需GPU）
python3 scripts/demo_12min.py --mode simulation

# 混合模式（部分真实，部分模拟）
python3 scripts/demo_12min.py --mode hybrid

# 真实模式（需要GPU和模型）
python3 scripts/demo_12min.py --mode real
```

### 5.3 验证服务状态

```bash
# 检查服务是否运行
curl http://192.168.1.103:8000/api/status

# 查看运行中的进程
ps aux | grep -E "start_monitor|demo_12min"

# 检查端口监听
netstat -tlnp | grep -E "8000|8765|43893"
```

## 七、性能优化建议

### 7.1 GPU加速（如配备）

```bash
# 检查GPU状态
nvidia-smi

# 安装GPU依赖
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

# 验证GPU可用
python3 -c "import torch; print(f'CUDA可用: {torch.cuda.is_available()}')"
```

### 7.2 内存优化

```bash
# 查看内存使用
free -h

# 清理系统缓存
sync && echo 3 > /proc/sys/vm/drop_caches
```

### 7.3 日志轮转

```bash
# 定期清理旧日志
find data/logs -name "*.log" -mtime +7 -delete

# 限制日志大小
echo "* * * * * find /home/ysc/lite3-power-inspection/data/logs -name '*.log' -size +10M -delete" | crontab -
```
