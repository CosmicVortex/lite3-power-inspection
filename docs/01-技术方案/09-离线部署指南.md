## 三、一键部署流程

### 步骤一：准备离线包（赛前有网络时）

在笔记本电脑上执行：

```bash
# 进入项目目录
cd /path/to/lite3-power-inspection

# 生成离线包（下载依赖wheel包）
python3 scripts/package_offline.py --output offline-deploy
```

生成的目录结构：

```
offline-deploy/
├── packages/              # Python依赖wheel包
│   ├── loguru-xxx.whl
│   ├── websockets-xxx.whl
│   ├── fastapi-xxx.whl
│   ├── uvicorn-xxx.whl
│   └── pydantic-xxx.whl
└── README.md
```

### 步骤二：传输到机器狗主机

**使用MobaXterm文件面板**：

1. 打开MobaXterm并连接到 `ysc@192.168.1.103`（密码：`'`）
2. 在左侧远程文件面板中，导航到 `/home/ysc/`
3. 将以下文件/文件夹从本地拖拽到远程：
   - `lite3-power-inspection.zip`（完整项目）
   - `offline-deploy/packages/`（依赖包，可选）

### 步骤三：SSH登录并部署

```bash
# SSH登录
ssh ysc@192.168.1.103
# 密码: '

# 一键部署
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
python3 -m venv venv && source venv/bin/activate

# 安装依赖（有离线包时使用）
pip install --no-index --find-links=/home/ysc/offline-deploy/packages -r requirements.txt

# 或使用网络安装
# pip install -q -r requirements.txt

# 创建目录并启动
mkdir -p data/logs data/cache models
chmod +x scripts/*.sh
```

### 步骤四：运行演示

```bash
# 启动监测平台（后台）
nohup python3 scripts/start_monitor.py > data/logs/monitor.log 2>&1 &

# 运行演示
python3 scripts/demo_12min.py --mode simulation
```

**访问地址**: http://192.168.1.103:8000

## 五、故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 密码错误 | 输入法为中文 | 按Shift切换英文输入法 |
| 端口被占用 | 旧进程残留 | `pkill -f start_monitor.py` |
| 依赖安装失败 | 离线包不完整 | 重新生成：`python3 scripts/package_offline.py` |
| 模块导入失败 | 未激活虚拟环境 | `source venv/bin/activate` |
