## 一、测试环境要求

### 硬件要求

| 项目 | 推荐配置 | 最低配置 |
|------|----------|----------|
| 感知主机 | Jetson Xavier NX 8GB | Jetson Nano |
| 运动主机 | RK3588 | RK3399 |
| 云台相机 | SR-UPA810T609 | 任意RTSP相机 |
| 监测平台 | x86_64 PC | 任意PC |

### 软件要求

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| Python | 3.8+ | 运行环境 |
| CUDA | 11.4+ | GPU加速 |
| TensorRT | 8.x | 推理加速 |
| OpenCV | 4.5+ | 图像处理 |

```bash
cd ~/lite3-power-inspection
```

```bash

# 验证感知模块
```
