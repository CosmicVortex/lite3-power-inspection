## 一、确认机器狗环境配置的必要性

在部署绝影Lite3电力巡检系统之前，必须确认机器狗主机的环境配置，包括：
- 操作系统版本
- Python版本
- GPU环境
- 网络连接状态
- 已安装的依赖包

确认环境配置可以：
1. 避免部署后的兼容性问题
2. 提前发现缺失的依赖组件
3. 确定是否需要安装GPU支持
4. 验证网络连通性

## 三、环境信息采集内容详解

### 3.1 系统信息

采集脚本将收集以下系统信息：

| 信息项 | 命令 | 示例输出 |
|--------|------|----------|
| 操作系统名称 | `uname -s` | Linux |
| 内核版本 | `uname -r` | 5.4.0-104-generic |
| 系统架构 | `uname -m` | aarch64 / x86_64 |
| 主机名 | `hostname` | lite3-nx |
| 操作系统版本 | `cat /etc/os-release` | Ubuntu 20.04.5 LTS |

**预期正常值**：
- 操作系统：Ubuntu 20.04 LTS
- 架构：aarch64（Jetson NX）或 x86_64
- 内核版本：>= 5.4

### 3.2 Python环境信息

| 信息项 | 命令 | 示例输出 |
|--------|------|----------|
| Python版本 | `python3 --version` | Python 3.8.10 |

| pip版本 | `pip3 --version` | pip 20.0.2 |
| 虚拟环境 | `which python` | /home/ysc/lite3-power-inspection/venv/bin/python |

**预期正常值**：
- Python版本：>= 3.8
- 建议使用虚拟环境

### 3.3 硬件信息

#### CPU信息

```bash
# CPU核心数

# CPU型号
```

**预期正常值**：

## 四、解读采集结果

### 4.1 系统信息解读

| 检查项 | 正常值 | 异常处理 |
|--------|--------|----------|
| 操作系统 | Ubuntu 20.04 LTS | 升级系统或使用容器 |
| Python版本 | >= 3.8 | 安装Python 3.8+ |
| 架构 | aarch64/x86_64 | 确认硬件兼容性 |
| CPU核心 | >= 4 | 正常 |
| 内存可用 | >= 4GB | 关闭其他进程 |

### 4.2 GPU环境解读

| 状态 | 含义 | 处理方式 |
|------|------|----------|
| ✓ GPU可用 | 支持真实模式 | 可安装TensorRT |
| ✗ GPU不可用 | 只能使用模拟模式 | 无需处理 |
| ⚠ CUDA版本低 | 可能影响性能 | 升级CUDA到11.4+ |

### 4.3 网络连通性解读

| 目标设备 | 状态 | 含义 |
|----------|------|------|
| 运动主机 | ✓ 可达 | 正常 |
| 云台相机 | ✗ 不可达 | 检查WiFi热点或网线 |
| 监测平台 | ✗ 不可达 | 检查网络配置 |

**注意**：网络不可达不影响模拟模式运行，仅影响真实硬件通信。

### 4.4 依赖包状态解读

| 状态 | 含义 | 处理方式 |
|------|------|----------|
| ✓ 已安装 | 依赖正常 | 无需处理 |
| ✗ 未安装 | 缺少依赖 | 运行安装命令 |

## 五、根据反馈调整环境

### 5.1 Python版本过低

**问题**：Python版本 < 3.8

**解决步骤**：

```bash
# 1. 检查当前版本
python3 --version

# 2. 安装Python 3.8
sudo apt-get update
sudo apt-get install python3.8 python3.8-venv python3.8-dev

# 3. 验证安装
python3.8 --version

# 4. 创建新虚拟环境
cd /home/ysc/lite3-power-inspection
python3.8 -m venv venv
source venv/bin/activate

# 5. 重新安装依赖
pip install -r requirements.txt
```

### 5.2 缺少核心依赖

**问题**：部分核心依赖未安装

**解决步骤**：

```bash
# 1. 激活虚拟环境
source venv/bin/activate

# 2. 查看缺失的依赖
pip list | grep -E "loguru|numpy|opencv|websockets|fastapi"

# 3. 安装缺失的依赖
pip install loguru numpy opencv-python websockets requests pyyaml fastapi uvicorn pydantic

# 或使用国内镜像加速
pip install loguru numpy opencv-python websockets requests pyyaml fastapi uvicorn pydantic -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 验证安装
python3 -c "import loguru, numpy, cv2, websockets, requests, yaml, fastapi, uvicorn, pydantic; print('✓ 所有核心依赖已安装')"
```

### 5.3 需要GPU支持

**问题**：需要运行真实模式（使用真实模型推理）

**解决步骤**：

```bash
# 1. 确认GPU和CUDA已安装
nvidia-smi
nvcc --version

# 2. 激活虚拟环境
source venv/bin/activate

# 3. 安装PyTorch（Jetson版本）
pip install torch==1.13.0 torchvision==0.14.0 --extra-index-url https://download.pytorch.org/whl/cu119

# 4. 安装TensorRT
pip install tensorrt==8.6.1

# 5. 安装ONNX
pip install onnx onnxruntime-gpu

# 6. 验证GPU支持
python3 -c "
import torch
print(f'PyTorch版本: {torch.__version__}')
print(f'CUDA可用: {torch.cuda.is_available()}')
if torch.cuda.is_available():
    print(f'GPU型号: {torch.cuda.get_device_name(0)}')
    print(f'显存: {torch.cuda.get_device_properties(0).total_mem / 1024**3:.1f} GB')
"
```

### 5.4 网络连接问题

**问题**：无法连接到目标设备

**解决步骤**：

```bash
# 1. 检查网络配置
ip addr show

# 2. 如果是笔记本热点模式
# 查看热点IP
ip addr show wlan0
# 应该是 192.168.1.1

# 3. 检查防火墙
sudo ufw status
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 8000/tcp  # HTTP
sudo ufw allow 8765/tcp  # WebSocket
sudo ufw allow 43893/udp # UDP控制
sudo ufw allow 554/tcp   # RTSP

# 4. 重启网络服务
sudo systemctl restart networking
# 或
sudo netplan apply
```

### 5.5 磁盘空间不足

**问题**：可用磁盘空间 < 2GB

**解决步骤**：

```bash
# 1. 检查磁盘使用
df -h

# 2. 清理无用文件
sudo apt-get clean
sudo apt-get autoremove

# 3. 清理日志
sudo journalctl --vacuum-time=3d

# 4. 检查大文件
sudo du -sh /var/log/*
sudo du -sh ~/.* 2>/dev/null | sort -rh | head -10
```
