## 一、系统架构说明

### 1.1 架构概述

本系统采用**单主机感知 + 独立监测平台**架构：

| 部署位置 | 内容 | IP地址 | 端口 |
|---------|------|--------|------|
| **感知主机** (Jetson NX) | 巡检程序、AI推理、数据采集、WebSocket客户端 | 192.168.1.103 | 43893/8080 |
| **监测平台** (独立笔记本) | FastAPI服务、Web界面、运动控制 | localhost | 8000/8765 |

> **重要说明**：监测平台独立运行在操作员笔记本上，监听本地8765端口等待感知主机连接。感知主机通过WebSocket主动连接笔记本的192.168.1.103:8765。

### 1.2 核心参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 感知主机IP | 192.168.1.103 | Jetson Xavier NX |
| 运动主机IP | 192.168.1.103 | RK3588（共享IP） |
| 云台相机IP | 192.168.1.108 | 静态配置 |
| UDP端口 | 43893 | 运动控制指令 |
| WebSocket端口 | 8765 | 数据上报 |
| 图片服务端口 | 8080 | 快照图片 |
| RTSP端口 | 554 | 视频流 |
| 心跳周期 | ≤500ms | UDP心跳 |
| 告警阈值 | 45℃/50℃ | 预警/告警 |

## 二、感知主机部署

### 2.1 环境要求

| 项目 | 要求 | 说明 |
|------|------|------|
| 操作系统 | Ubuntu 20.04 LTS | 已预装 |
| Python版本 | 3.8+ | 已预装3.8.10 |
| CUDA | 已安装 | GPU计算加速 |
| PyTorch | 已安装 | 深度学习框架 |

### 2.2 一键部署命令

```bash
# SSH登录感知主机
ssh ysc@192.168.1.103
# 密码: '（英文单引号）

# 解压部署包并一键部署
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip

```

### 2.3 部署包信息

```
文件名: lite3-power-inspection.zip
大小: 约 15.6 MB
内容: 
  - src/: 源代码（巡检程序）
  - models/: AI模型文件
  - docs/: 技术文档
  - scripts/: 部署脚本
  - config/: 配置文件
```

### 2.4 验证安装


## 四、网络配置

### 4.1 网络连接验证

```bash
# 验证感知主机连通性
ping -c 2 192.168.1.103

# 验证端口开放
nc -zv 192.168.1.103 8765
nc -zv 192.168.1.103 43893

# 验证监测平台
curl http://localhost:8000/health
```

### 4.2 启动顺序

```
1. 先启动监测平台（笔记本）
   → 打开 http://localhost:8000
   
2. 再启动感知主机巡检程序
   → 自动连接监测平台
   
3. 等待WebSocket连接成功
   → 界面显示"已连接"
```

## 六、故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| WebSocket连接失败 | 网络不通 | 检查IP配置和防火墙 |
| 监测平台无数据 | 感知主机未启动 | 检查run_demo.py是否运行 |
| 运动控制无响应 | UDP被拦截 | 检查运动主机状态 |
| 视频流无法显示 | RTSP服务异常 | 检查云台相机连接 |
| 端口被占用 | 其他服务占用 | `pkill -f start_monitor.py` |

## 七、完整部署流程总结

```bash
# ========== 赛前准备 ==========
# 1. 生成离线包（有网络时）
python3 scripts/package_offline.py --output offline-deploy

# 2. 传输部署包
scp lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/
scp monitor-platform-portable.zip user@laptop:/tmp/

# ========== 比赛当天 ==========
# 3. 感知主机部署（SSH登录）
ssh ysc@192.168.1.103
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
./scripts/deploy.sh simulation

# 4. 监测平台部署（笔记本）
cd /tmp && unzip -q monitor-platform-portable.zip
cd monitor-platform
./start_monitor.sh   # Linux
# 或 start_monitor.bat  # Windows

# 5. 验证连接
# 浏览器打开 http://localhost:8000
# 确认显示"已连接"和实时数据
```

## 九、配置文件说明

### 9.1 主要配置项（config/inspection_config.yaml）

```yaml
network:
  robot_motion:
    ip: "192.168.1.103"      # 运动主机IP
    port: 43893               # UDP端口
  websocket:
    server_url: "ws://192.168.1.103:8765/ws"  # 监测平台地址

camera:
  streams:
    visible_light_main: "rtsp://admin:123456@192.168.1.108:554/id=1&type=0"
    thermal: "rtsp://admin:123456@192.168.1.108:554/id=2&type=0"

perception:
  temperature:
    warn_threshold: 45.0      # 预警阈值
    critical_threshold: 50.0  # 告警阈值
```
