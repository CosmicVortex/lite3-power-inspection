## 一、感知主机部署（Jetson NX）

### 1.1 传输部署包

通过 MobaXterm 的 SFTP/SCP 功能，将 `deliverables/lite3-power-inspection.zip` 复制到感知主机：

```bash
# 在 Windows 电脑上，MobaXterm SSH 会话中执行：
scp /c/Users/你的用户名/Downloads/lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/
# 密码: '（英文单引号）
```

### 1.2 解压并安装依赖

```bash
# SSH登录
ssh ysc@192.168.1.103
# 密码: '

# 解压部署包
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ~/lite3-power-inspection.zip

# 安装依赖（离线模式）
chmod +x scripts/offline_install.sh
./scripts/offline_install.sh sensors
```

### 1.3 配置 WebSocket 地址

**重要！** 修改配置文件中的监测平台地址：

```bash
# 查看笔记本IP地址
ipconfig  # 在Windows电脑上执行

# 在感知主机上修改配置（将 <笔记本IP> 替换为实际IP）
sed -i 's|ws://MONITOR_HOST:8765/ws|ws://192.168.1.XXX:8765/ws|' config/inspection_config.yaml

# 验证修改结果
grep "server_url" config/inspection_config.yaml
```

### 1.4 运行演示

```bash
cd ~/lite3-power-inspection
python3 scripts/run_demo.py --mode simulation
```

## 二、监测平台部署（Windows 笔记本）

### 2.1 获取便携包

从 GitHub 或项目目录复制 `deliverables/monitor-platform-portable.zip` 到笔记本。

### 2.2 一键启动

```cmd
:: 1. 解压到任意目录（如 D:\monitor-platform）
:: 2. 双击运行
start_monitor.bat

:: 3. 访问监测平台
:: http://localhost:8000
```

---

## 三、启动顺序

```
1. 先启动监测平台（笔记本）
   → 双击 start_monitor.bat
   → 等待出现 "Monitor Platform Started Successfully!"

2. 再启动感知主机巡检程序
   → SSH登录感知主机
   → python3 scripts/run_demo.py --mode simulation

3. 验证连接
   → 浏览器打开 http://localhost:8000
   → 确认显示"已连接"和实时数据
```

## 四、常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| WebSocket连接失败 | 未修改配置文件中的MONITOR_HOST | 执行sed命令替换为笔记本实际IP |
| 监测平台无数据 | 感知主机未启动或WebSocket未连接 | 检查run_demo.py是否在运行 |
| 端口8765被占用 | 其他服务占用 | `netstat -ano | findstr :8765` 查找并终止进程 |
| start_monitor.bat报错 | server.py路径错误 | 已修复，请重新下载便携包 |
