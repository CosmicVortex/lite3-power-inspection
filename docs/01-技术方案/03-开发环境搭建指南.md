## 二、环境安装步骤

### 2.1 克隆项目仓库

```bash
git clone https://github.com/CosmicVortex/lite3-power-inspection.git
cd lite3-power-inspection
```

### 2.2 创建Python虚拟环境

```bash
# 使用venv（推荐）
python3 -m venv venv
source venv/bin/activate

# 或使用conda
conda create -n inspection python=3.9
conda activate inspection
```

### 2.3 安装Python依赖

```bash
# 安装项目依赖
pip install -r requirements.txt

# 安装监测平台依赖
pip install -r monitor_platform/requirements.txt
```

> **注意**：项目使用单一 `requirements.txt` 管理所有依赖，不再分拆为 core/perception/gateway/dev 多个文件。

**核心依赖清单**：

| 包名 | 版本 | 用途 |
|------|------|------|
| numpy | >=1.21.0 | 数值计算 |
| opencv-python | >=4.5.0 | 图像处理 |
| torch | >=2.0.0 | 深度学习框架 |
| tensorrt | >=8.0.0 | GPU推理加速 |
| onnx | >=1.12.0 | 模型交换格式 |
| onnxruntime-gpu | >=1.14.0 | ONNX推理 |
| websockets | >=10.0 | WebSocket通信 |
| requests | >=2.28.0 | HTTP请求 |
| pyyaml | >=6.0 | 配置文件解析 |
| av | >=10.0 | 视频处理 |
| loguru | >=0.6.0 | 日志管理 |

### 2.4 安装系统依赖

```bash
# Ubuntu 20.04
sudo apt-get update
sudo apt-get install -y \
    librealsense2-utils \
    libusb-1.0-0-dev \
    pkg-config \
    cmake \
    git \
    curl \
    wget \
    ffmpeg \

```

### 2.5 安装TensorRT

```bash
# 从NVIDIA官网下载TensorRT
wget https://developer.nvidia.com/downloads/compute/machine-learning/tensorrt/secure/8.x/packages/TensorRT-8.x.x.x/python/tensorrt-8.x.x.x-cp38-none-linux_x86_64.whl

# 安装
pip install tensorrt-8.x.x.x-cp38-none-linux_x86_64.whl

# 验证安装
python -c "import tensorrt; print(tensorrt.__version__)"
```

## 三、硬件连接配置

### 3.1 网络配置

**Jetson NX静态IP配置**：

```bash
sudo nano /etc/netplan/01-netcfg.yaml
```

```yaml
network:
  ethernets:
    eth0:
      dhcp4: no
      addresses: [192.168.1.103/24]
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
  version: 2
```

**应用配置**：
```bash
sudo netplan apply
```

### 3.2 云台相机配置

通过Web界面或厂商工具配置云台静态IP：
- IP: 192.168.1.108
- 子网掩码: 255.255.255.0
- 网关: 192.168.1.1

### 3.3 连接验证

```bash

# 测试云台HTTP API
```

## 四、模型部署

### 4.1 YOLOv8模型转换

```bash
# 1. 导出ONNX模型
yolo export model=yolov8s.pt format=onnx opset=11 simplify

# 2. 转换为TensorRT引擎
trtexec --onnx=yolov8s.onnx \
        --saveEngine=yolov8s.trt \
        --fp16 \
        --workspace=1024 \
        --minTiming=100 \
        --iter=1000 \
        --timeout=300
```

### 4.2 U-Net模型转换

```bash
# 1. 导出ONNX模型
python export_onnx.py --model unet-crack.pt --output unet-crack.onnx

# 2. 转换为TensorRT引擎
trtexec --onnx=unet-crack.onnx \
        --saveEngine=unet-crack.trt \
        --fp16 \
        --workspace=512
```

### 4.3 模型验证

```python
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoprimaryctx

# 加载引擎
logger = trt.Logger(trt.Logger.WARNING)
with open("yolov8s.trt", "rb") as f:
    engine = trt.Runtime(logger).deserialize_cuda_engine(f.read())

# 验证推理
context = engine.create_execution_context()
print(f"Engine loaded successfully")
print(f"Input bindings: {engine.num_inputs}")
print(f"Output bindings: {engine.num_outputs}")
```

## 五、常见问题排查

### 5.1 TensorRT导入失败

```bash
# 检查CUDA版本
nvcc --version

# 检查TensorRT版本
python -c "import tensorrt; print(tensorrt.__version__)"

# 重新安装
pip uninstall tensorrt
pip install tensorrt==8.x.x.x
```

### 5.2 视频流无法拉取

```bash
# 检查网络
ping 192.168.1.108

# 检查RTSP端口
nc -zv 192.168.1.108 554

# 使用ffprobe测试
ffprobe rtsp://admin:123456@192.168.1.108:554/id=1&type=0

# 检查防火墙
sudo ufw status
sudo ufw allow 554/tcp
```

### 5.3 UDP通信超时

```bash
# 检查运动主机IP
ping 192.168.1.103

# 查看UDP端口监听
netstat -uln | grep 43893

# 测试UDP通信
python -c "
import socket
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.sendto(b'\x01\x00\x04\x21\x00\x00\x00\x00\x00\x00\x00\x00', ('192.168.1.103', 43893))
sock.settimeout(1.0)
try:
    data, addr = sock.recvfrom(1024)
    print(f'Received: {data.hex()}')
except socket.timeout:
    print('Timeout')
"
```

## 七、环境变量配置

创建 `~/.inspection_env` 文件：

```bash
# 项目路径
export PROJECT_HOME=~/lite3-power-inspection

# Python路径
export PYTHONPATH=${PROJECT_HOME}/src:${PYTHONPATH}

# 模型路径
export MODEL_PATH=${PROJECT_HOME}/models

# 日志路径
export LOG_PATH=${PROJECT_HOME}/data/logs
```

在 `~/.bashrc` 中添加：
```bash
source ~/.inspection_env
```
