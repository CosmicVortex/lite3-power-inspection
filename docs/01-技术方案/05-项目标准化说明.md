## 二、部署包说明

### 2.1 感知主机部署包

**文件名**: `deliverables/lite3-power-inspection.zip`  
**大小**: 约 111 MB  
**包含内容**:
- 完整源代码（src/）
- 离线依赖包（offline-deploy/sensors/，26个wheel包）
- 配置文件（config/inspection_config.yaml）
- 启动脚本（scripts/run_demo.py, scripts/offline_install.sh/bat）
- 技术文档（docs/）

**部署步骤**:
```bash
# 1. SSH登录感知主机
ssh ysc@192.168.1.103
# 密码: '（英文单引号）

# 2. 解压部署包
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ~/lite3-power-inspection.zip

# 3. 安装依赖（离线模式）
./scripts/offline_install.sh sensors

# 4. 配置WebSocket地址
sed -i 's|ws://MONITOR_HOST:8765/ws|ws://<笔记本IP>:8765/ws|' config/inspection_config.yaml

# 5. 运行演示
python3 scripts/run_demo.py --mode simulation
```

### 2.2 监测平台便携包

**文件名**: `deliverables/monitor-platform-portable.zip`  
**大小**: 约 14 KB  
**包含内容**:
- 主程序：`server.py`
- 启动脚本：`start_monitor.sh` / `start_monitor.bat`
- 依赖清单：`requirements.txt`

**部署步骤**:
```cmd
:: Windows
:: 1. 解压到任意目录（如 D:\monitor-platform）
:: 2. 双击运行
start_monitor.bat
:: 3. 访问 http://localhost:8000
```

## 三、配置参数标准

### 3.1 网络配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 运动主机IP | 192.168.1.103 | 与感知主机共享 |
| 云台IP | 192.168.1.108 | 静态配置 |
| UDP控制端口 | 43893 | 运动指令 |
| UDP数据端口 | 43894 | 状态上报 |
| WebSocket端口 | 8765 | 数据通信 |
| HTTP服务端口 | 8000 | 监测平台 |
| 快照服务端口 | 8080 | 检测图片 |
| RTSP端口 | 554 | 视频流 |

### 3.2 WebSocket地址配置

**配置文件**: `config/inspection_config.yaml`
```yaml
network:
  websocket:
    server_url: "ws://MONITOR_HOST:8765/ws"  # TODO: 部署时替换为监测平台实际IP
```

**部署时必须执行**:
```bash
sed -i 's|ws://MONITOR_HOST:8765/ws|ws://<笔记本IP>:8765/ws|' config/inspection_config.yaml
```

或使用命令行参数覆盖:
```bash
python3 scripts/run_demo.py --mode simulation --ws-url ws://<笔记本IP>:8765/ws
```
