## 三、解压与部署

### 3.1 确定部署路径

根据官方文档，推荐部署路径：

```bash
# 官方推荐路径
/home/ysc/lite3-power-inspection/

# 备选路径（如果需要）
/home/ysc/projects/lite3-power-inspection/
```

### 3.2 创建Python虚拟环境

```bash
# 进入项目目录
cd /home/ysc/lite3-power-inspection

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 验证Python版本
python --version
# 应该输出: Python 3.x.x
```

### 3.3 安装依赖

```bash
# 安装核心依赖（必需）
pip install -r requirements.txt

# 安装GPU依赖（可选，仅真实模式需要）
# pip install -r requirements-gpu.txt

# 验证安装
pip list | grep -E "loguru|numpy|opencv|websockets|fastapi"
```

### 3.4 配置环境变量

```bash
# 编辑bashrc
nano ~/.bashrc

# 添加以下内容
export PROJECT_HOME=/home/ysc/lite3-power-inspection
export PYTHONPATH=${PROJECT_HOME}/src:${PYTHONPATH}
export MODEL_PATH=${PROJECT_HOME}/models
export LOG_PATH=${PROJECT_HOME}/data/logs

# 保存并生效
source ~/.bashrc
```

### 3.5 创建必要目录

```bash
# 创建数据目录
mkdir -p data/logs
mkdir -p data/cache
mkdir -p models

# 设置权限
chmod 755 scripts/*.sh
chmod 755 scripts/*.py
```

### 3.6 验证配置

```bash
# 检查配置文件
cat config/inspection_config.yaml

# 验证Python路径
python -c "import sys; sys.path.insert(0, 'src'); from src.services.simulation_generator import SimulationDataGenerator; print('✓ 导入成功')"
```

## 六、常见问题排查

### 6.1 依赖安装失败

**症状**: `pip install` 报错

**解决方案**:
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 升级pip
python -m pip install --upgrade pip

# 安装系统依赖
sudo apt-get install python3-dev python3-pip libffi-dev
```

### 6.2 模块导入失败

**症状**: `ModuleNotFoundError: No module named 'xxx'`

**解决方案**:
```bash
# 检查虚拟环境
which python
# 应该指向 venv/bin/python

# 重新安装依赖
pip install loguru numpy opencv-python websockets requests pyyaml fastapi uvicorn pydantic

# 检查Python路径
python -c "import sys; print('\n'.join(sys.path))"
```

### 6.3 网络连接失败

**症状**: 无法连接到192.168.1.103

**解决方案**:
```bash
# 检查网络配置
ip addr show

# 测试连通性
ping -c 3 192.168.1.103

# 检查防火墙
sudo ufw status
sudo ufw allow 22/tcp
sudo ufw allow 8000/tcp
sudo ufw allow 8765/tcp
sudo ufw allow 43893/udp
```

### 6.4 端口被占用

**症状**: `Address already in use`

**解决方案**:
```bash
# 查找占用端口的进程
sudo lsof -i :8000
sudo lsof -i :8765

# 杀死占用进程
sudo kill -9 <PID>

# 或使用不同端口启动
python3 scripts/start_monitor.py --port 8080 --ws-port 8766
```
