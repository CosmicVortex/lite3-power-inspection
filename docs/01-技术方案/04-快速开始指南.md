## 二、一键部署

### 步骤一：传输部署包

在笔记本电脑上使用MobaXterm，将 `lite3-power-inspection.zip` 复制到机器狗主机：

```bash
# 方法A：MobaXterm文件面板拖拽
# 将本地文件拖到远程 /home/ysc/ 目录

# 方法B：SCP命令
scp lite3-power-inspection.zip ysc@192.168.1.103:/home/ysc/
```

### 步骤二：SSH登录并部署

```bash
# SSH登录
ssh ysc@192.168.1.103
# 密码: '

# 一键部署（全部执行）
cd ~ && mkdir -p lite3-power-inspection && cd lite3-power-inspection
unzip -q ../lite3-power-inspection.zip
python3 -m venv venv && source venv/bin/activate
pip install -q -r requirements.txt
```

## 三、启动系统

### 方式一：启动监测平台（后台）

```bash
source venv/bin/activate
nohup python3 scripts/start_monitor.py > data/logs/monitor.log 2>&1 &
```

访问地址：**http://192.168.1.103:8000**

### 方式二：运行演示

```bash
source venv/bin/activate

# 完整12分钟演示
python3 scripts/demo_12min.py --mode simulation

# 快速3分钟演示
python3 scripts/demo_12min.py --mode simulation --fast
```

### 方式三：使用一键脚本

```bash
./scripts/deploy.sh simulation
```

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| 密码错误 | 切换到英文输入法，密码为英文单引号 `'` |
| 端口占用 | `pkill -f start_monitor.py` 后重试 |
| 依赖安装失败 | `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 模块导入失败 | 确认已激活虚拟环境：`source venv/bin/activate` |
