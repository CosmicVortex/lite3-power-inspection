重要安全提示
在启动绝影Lite3 之前，请确保机器狗周围有1 米以上的空间，避免与人
或物体发生碰撞。
• 机器狗通过楼梯或斜坡时，请勿站在机器狗下方的楼梯、平台或斜坡上，
以避免机器狗跌落时可能会造成的人员损伤。
• 当机器狗在使用过程中出现腿乱摆、剧烈晃动等非正常现象时，请按
下【紧急停止】键以启动软急停功能，使正在运动的机器狗进入保护
状态。机器狗将自动趴下，待排查问题后，再解除紧急停止即可正常
操作机器狗。

动停止运动，原地下趴，请等待其降至室温后再继续操作机器狗运动。

3.10.1 紧急停止
当机器狗在使用过程中出现腿乱摆、剧烈晃动等非正常现象时，请按下【⑦紧急停止】键以
启动软急停功能，使正在运动的机器狗进入保护状态。机器狗将自动趴下，待排查问题后再
解除急停状态，然后继续操作机器狗。
3.10.3 摔倒爬起
当机器狗意外摔倒时，请根据机器狗周围障碍物情况选择爬起方向：若机器狗左侧有障碍物

4 注意事项
4.1 使用环境注意事项
• 请勿在高压电线、高压输电站、移动电话基站和电视广播信号塔等电
磁干扰严重的环境下操控机器狗。
• 请勿在 WiFi 信号干扰严重的环境下操控机器狗，务必关闭部分或全部
其他无线设备 WiFi 信号源，然后再使用“云深处科技”APP 操控机器狗。
• 请勿在有雾、下雪、下雨、雷电、沙暴、暴风、龙卷风等恶劣天气运
行机器狗。
• 请保持在视线范围内控制机器狗，使机器狗时刻与人群、水面、明火
等保持至少1 米以上的安全距离。
• 在冰面、玻璃、瓷砖等光滑地面使用机器狗时，请避免剧烈运动，降
低机器狗的行走速度并使用抓地步态，防止机器狗因足底打滑而摔倒。
• 请勿在高处边缘运行机器狗，以防其从高处坠落造成损伤。
4.3 其他注意事项
• 搬运机器狗时，注意机器狗上面的防夹手标签，严禁将手伸入贴有防
夹手标签的位置！
• 注意机器狗上面的防拆标签，严禁私自拆卸机器狗，一经拆卸，保修
无效！
4.2 电池注意事项
• 电池内部接触到水后可能会发生分解反应，从而引发电池自燃，甚至
引发爆炸。因此严禁使电池接触任何液体，切勿将电池浸入水中或弄湿，
切勿在雨中或潮湿环境中使用电池。如电池意外坠入水中，请立即将
电池置于安全的开阔区域并远离电池直至电池完全晾干。晾干的电池
不得再次使用。
• 严禁使用鼓包、漏液、破损的电池以及对其充电。当电池出现异味、变形、
变色或其他任何异常现象时不得使用。若电池发生异常情况，请联系
售后做进一步处理。
• 禁止擅自拆卸电池。一旦拆卸，不予保修。因拆卸电池引发的电池事故，
云深处科技一律不予负责。
• 每隔3 个月左右重新充放电一次以保持电池活性。
• 详细的注意事项请参考电池说明书。

5 常见问题与解决
Q1：机器狗自己停止运动是正常现象吗？
A：可能是电机或驱动器过温保护，请等待10 分钟后再次尝试。若依然无法控制机器狗继续
运动，请检查电量是否充足。
Q2：机器狗由于某条腿失控摔倒该如何处理？
A：先点击【⑦紧急停止】键使其趴下，然后重启机器狗。若重启后仍未恢复正常，请联系售后。
Q3：机器狗摔倒后视频流卡住该如何处理？
A：重启机器狗。若重启后视频流依然没有恢复正常，请联系售后。
Q4：遇到查阅本手册后依然无法解决的问题时该如何处理？
A：在运动设置中点击【㉘保存数据】键并及时联系售后。
