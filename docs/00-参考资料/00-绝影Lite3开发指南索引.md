## 指南内容概览

### 1. 运动开发指南

该指南介绍了绝影Lite3运动主机的开发方法，包含如下内容：

- **运动系统架构**：绝影Lite3机器人的运动系统架构，包括身体、关节、足底及IMU坐标系定义与规格参数
- **运动控制SDK**：基于Lite3运动控制SDK进行算法二次开发的完整流程、程序架构与关键步骤
- **强化学习训练**：RL训练框架的使用和部署

开发者可据此在Lite3上实现机器人的运动控制开发。

#### 目录结构

```
1. 运动系统
   1.1 坐标系
     1.1.1 身体坐标系
     1.1.2 关节及足底坐标系
     1.1.3 本体传感器坐标
   1.2 规格参数
     1.2.1 身体参数
     1.2.2 腿部参数
     1.2.3 关节硬件参数
     1.2.4 关节性能参数
   1.3 日志功能
   1.4 系统保护
     1.4.1 过温保护
     1.4.2 摔倒保护
2. 运动控制算法开发
   2.1 强化学习运动控制算法开发与部署
   2.2 传统运动控制SDK
     2.2.1 程序流程
     2.2.2 开发步骤
```

### 2. 感知开发指南

该指南介绍了绝影Lite3感知主机的开发方法，包含如下内容：

- **开发环境准备**：完整开发环境准备及配置流程，包括远程登录、ROS版本查看与切换、深度相机驱动与测试方法
- **三大核心功能软件包**：
  - 运动通信功能包，实现机器人ROS与UDP协议转换
  - 识别跟随功能包，基于YOLOv8和DeepStream实现人体识别与自动跟随
  - 基于激光雷达的建图、定位、导航与避障功能包，提供从SLAM建图到自主导航的全套解决方案

开发者可直接依照该指南完成上位机与机器人的感知数据交互与功能开发。

#### 目录结构

```
1. 感知系统
2. 准备工作
   2.1 远程登录
   2.2 通过HDMI连接到感知主机
3. ROS版本查看与切换
4. 深度相机
   4.1 相机驱动
   4.2 相机测试
   4.3 librealsense二次开发
   4.4 Realsense-ROS1二次开发
   4.5 Realsense-ROS2二次开发
5. 运动通信功能包
6. 识别跟随功能包
7. 基于激光雷达的建图定位导航避障（ROS1）
8. 基于激光雷达的建图定位导航避障（ROS2）
```

## 快速开始

### 硬件连接

1. **WiFi连接**：将开发主机连接到绝影Lite3的WiFi
2. **SSH远程登录**：
   ```bash
   ssh ysc@192.168.1.103
   # 密码：英文单引号 '
   ```
3. **NoMachine远程桌面**：输入IP `192.168.1.103`，用户名 `ysc`，密码 `'`

### 网络拓扑

| 设备 | IP地址 | 说明 |
|------|--------|------|
| 监测平台 | 192.168.1.200 | 上位机/服务器 |
| 云台相机 | 192.168.1.108 | 双光谱云台 |
| 感知主机 | 192.168.1.103 | Jetson NX |
| 运动主机 | 192.168.1.103 | RK3588 |
