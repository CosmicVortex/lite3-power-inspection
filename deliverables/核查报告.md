## 六、部署验证步骤

### 监测平台部署
```bash
# 1. 解压
unzip monitor_platform_v1.7.zip
cd monitor_platform

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
./scripts/start_monitor.sh

# 4. 访问界面
# http://localhost:8000
```

### 感知主机部署
```bash
# 1. 解压
unzip perception_host_v1.7.zip
cd perception_host

# 2. 安装依赖
pip install -r requirements.txt
# 或离线安装
pip install packages/*.whl

# 3. 修改配置
vim config/inspection_config.yaml
# 将 MONITOR_HOST 替换为监测平台IP

# 4. 启动演示
python3 scripts/run_demo.py --mode simulation
# 或连接到远程监测平台
python3 scripts/run_demo.py --mode hybrid --ws-url ws://192.168.1.200:8765/ws
```
